# logical-math

數學學習日誌。走的是**邏輯輪廓**路線：只要概念、結構、為什麼，不發展計算技術。這是一本**回顧集**：目的是弄懂底層的邏輯框架，收錄的是多次來回校正後確認過的概念框架——正確、有效、有意義的理解，不是練習簿，所以筆記裡沒有待填的空格。從機率基礎、統計推論、RTP / 獎池的應用模型，一路到複數、向量、數理邏輯，再從向量線延伸到 LLM 訓練裡的梯度，記錄概念、被校正過的混淆與每個主題的一句話濃縮版。

## 背景

- 後端 / 基礎設施背景，非數學本科。微積分只當記號理解（Σ 的連續版）
- 應用情境：遊戲機率、RTP、獎池經濟系統
- 學習方式：**種子優先、演繹式**（seed-first, deductive），不靠歸納現象、不用程式碼或模擬

## 學習方式

不照課綱線性前進，而是從一顆「種子」（根定義）出發，把整個主題演繹成一棵概念樹，再嫁接到既有的樹上。計算技術是刻意不發展的取捨，不是待補的缺口。每條線的流程：

1. 導師先給一句**種子**（如「誤差 = 觀測值 − 均值」），我不需要先提總結
2. 從種子**演繹**出主要結論，每一步說明「為什麼非如此不可」
3. **嫁接**：把新概念接到已有的概念樹上，指出接在哪一篇、哪一段
4. **記號最後**：公式只在最後出現，純當記號
5. 我用自己的話復述，導師判定「對／不對／一半對」，分開「實質主張」與「用詞」
6. 下 `/note` 把這條線沉澱成一份筆記，存進 `notes/`；復述確認後條目才記為 ✅，之前標 🔄；搞錯過的點永久保留為 ⚠️

驗證只用三種免程式方法：**復述測試**（用自己的話重述）、**一致性測試**（手填小表格，檢查結論互不矛盾）、**極端案例測試**（代入邊界值看是否崩壞）。
