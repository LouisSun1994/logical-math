# 「疊加」拆開來：深度、寬度、可靠度、封箱（Depth / Width / Reliability / Chunking）

- 來源：對話「我姑且稱之為疊加：genAI 能無限制疊加，人做不到」→「深度、寬度、可靠度、封箱是什麼意思」→「這是認知科學嗎」→「寬度這麼大，我怎麼沒被驚艷」→「你非生命，不可能主動」→「這段是不是在講 AI 生成是否為真」→「我天馬行空算不算寬度變大」→「人的寬度有界嗎，這是天賦吧」
- 目前定位：趣談（人和 AI 各自怎麼思考的後設層）。不在主線階段路線圖內。**這四個詞擺在一起比較人和 AI，是導師為了回答我而拼裝的說法，不是有名字的既有理論**；等級見 07 筆記「定理 vs 定律 vs 說法」段。第 2、4、5 段多為 🔄。

---

## 0. 一句話版本

**「疊加」一個詞裡混了三個可以分開量的東西（接了幾步、一次握幾個、每步對不對）和一個人類的技巧（封箱）。AI 贏在寬度與速度；生成當下兩邊都不驗真假；人的格子數有界，但箱子大小無界。**

## 2. 拆成四個詞

**種子：疊加 = 把上一步的輸出當成下一步的輸入（合成，composition）。**

貫穿的例子，查一個線上 bug：

```
使用者回報付款失敗 → API log 看到 timeout → 查下游服務 → DB 連線池滿了 → 某個 query 沒釋放連線
```

- 🔄 **深度（depth）**：後一步要用前一步的結論當起點，這樣接了幾次。上面那條鏈是 4。
- ✅ **寬度（width）**：每一次推論當下，能同時接納多少。查到連線池那一步，腦中同時握著 request id、時間點、哪個服務、目前的假設，寬度 4。
- 🔄 深度是前後相接，寬度是同時在場，兩者互相獨立。
- 🔄 **可靠度（reliability）**：鏈上任何一步錯了，後面全部作廢。跟串聯服務的可用率是同一件事：每個 99%，串 100 個只剩約 37%（假設各步獨立，示意用）。鏈越深，對單步的要求越苛刻。
- 🔄 **封箱（chunking）**：一段驗證過的鏈貼上名字，之後當「一步」用。說「連線池洩漏」五個字，裡面封著整條 4 步的鏈。它同時做兩件事：深度被藏起來（4 步變 1 步），寬度被釋放（一個名字只佔一格）。
- 🔄 箱子封之前要驗過，否則是在沙上蓋樓。
- ✅ 人之所以能想得很深，是因為封裝：直接站在現成的定理上。

| | 深度 | 寬度 |
|---|---|---|
| 順著一條線查 20 步，每步只需記上一步的結論 | 高 | 低 |
| 開會時同時比較 9 個方案的優缺點 | 低 | 高 |

| 詞 | 來自哪個領域 | 原名 | 性質 |
|---|---|---|---|
| 寬度 | 認知科學 | working memory（工作記憶） | 實驗測出來的，約 4（Cowan 2001） |
| 封箱 | 認知科學 | chunking | 實驗觀察 |
| 深度 | 計算機科學、邏輯 | depth（電路深度、證明長度、遞迴深度） | 定義 |
| 可靠度 | 機率、可靠度工程 | series system reliability（串聯系統） | 算術 |

類比：封箱就是寫 function，把一段邏輯包起來，呼叫時只記名字。失效處：function 不懂內部也能呼叫；數學的箱子至少要有人打得開，不然不算數。

> 濃縮：深度是接了幾步，寬度是一次握幾個，可靠度是每步對不對，封箱是把走通的一段縮成一個名字，好讓有限的寬度疊出很深的深度。

## 3. 人 vs AI：差在哪一個

**種子：把「AI 能做人做不到的疊加」拆開問：四個詞裡，差的是哪一個。**

- ✅ 牆是硬體的牆，不是邏輯的牆。
- ✅ AI 是真的拿一大片前文在做每一步推論；人是靠封箱。
- ⚠️ 「AI 能無限制地疊加」→ 不對。AI 的寬度同樣有限且有界（上界是 context 長度），只是大了好幾個量級；可靠度那道牆跟人共用。
- 🔄 深度兩邊都靠外部記錄：人用紙，AI 把中間結果寫出來再讀回去。
- ✅ 目前的 AI 是被動的。
- ⚠️ 「非生命、沒有自己的目的，所以不可能主動」→ 一半對。拿來描述現況成立；錯的只有「不可能」那一步。主動需要目的、觸發、一份關於對方的模型；後兩樣是工程，目的可以用借的（我交代「盯著某件事，有變化就告訴我」，那次主動的目的來自我）。
- ✅ 人和 AI 是雙生：互補，不是誰追上誰。

| | 人 | AI |
|---|---|---|
| 深度 | 靠封箱和紙，可以很深 | 靠寫出來再讀回去，可以很深 |
| 寬度 | 約 4 格 | 整段前文（幾十萬 token） |
| 可靠度 | 每步可能錯 | 每步可能錯 |
| 封箱 | 主要武器 | 大多是從人類文字繼承來的現成箱子 |

| | 缺什麼 | 有什麼 |
|---|---|---|
| 人 | 寬度 | 目的、意義、在乎什麼 |
| AI | 自己的目的 | 寬度、速度 |

交界是箱子（種子、濃縮、筆記）：唯一過得了 4 格窄門的格式。

> 濃縮：AI 贏在寬度和速度，深度兩邊都靠外部記錄，可靠度是同一道牆；兩邊缺的剛好是對方有的。

## 4. 生成 ≠ 為真：一張機率表、一次骰子

**種子：生成 = 根據前文算出一張「下一個字的機率表」，擲一次骰子取一個字，接上去，再重複。**

- ✅ 這整條線收斂到同一件事：AI 生成是否為真的底層概念。產出可以非常多，但不是每個都真。
- ✅ 生成當下不驗真假。我天馬行空時也一樣：想得出很多，大部分是無稽之談。
- 🔄 為什麼敢肯定：那張表是用人類文字訓練出來的，量的是「像不像人會寫的下一個字」；「真不真」沒有出現在訓練目標裡。像是指標，真是目標，大多同向，但不保證。
- ⚠️ 「不同權重下自然產出很多種」→ 不對。權重是固定的；多樣性來自骰子。同一個問題問 5 次得到 5 種答案，是擲了 5 輪。
- ⚠️ 「每個字都各推一種情境、全部攤開」→ 不對。每一步只有一張表、取一個字；一段回答是一條路徑。1 萬種是擲 1 萬次，不是同時握著 1 萬個。
- 🔄 寬度的真正位置：算每一張表時看得到多少前文。它讓第 9,000 個點子不跟第 3 個重複，但不負責產生點子。
- ⚠️ 「我天馬行空想很多，所以寬度超出常人」→ 不對。那是產量變大；想到第 30 個時，第 3 個已經不在腦中，寬度還是 4 格。
- 🔄 1 萬種解析攤開來，多半是幾十條獨立的軸互相組合；值得要的是沒想過的軸，不是數量。

| | 我天馬行空 | AI 生成 |
|---|---|---|
| 一次出幾個 | 一個接一個 | 一個接一個 |
| 產出當下有驗真假嗎 | 沒有 | 沒有 |
| 多樣性來源 | 聯想 | 擲骰子 |
| 大部分產出是 | 無稽，一眼篩得掉 | 像真的，不容易篩 |
| 這算寬度嗎 | 不算，是產量 | 也不算 |

類比：權重是寫死的轉輪配置，每個字是轉一次，一段回答是連轉幾百次的一條路徑。失效處：轉輪每一轉的機率表不變；生成每取一個字，下一張表就跟著整段前文重算，比 03 筆記「籤筒：不放回是刻意的設計」段的不放回變得更徹底。

> 濃縮：每一步只算一張「像不像」的機率表、擲一次骰子；產量來自多擲幾次，寬度只是每次擲之前看得到多少前文，真假要另外驗。

## 5. 人的寬度有界，箱子無界

**種子：格子數和一格裝多少，是兩個量。**

- 🔄 寬度有限且有界：實驗量到的大約落在 3 到 5，沒有人量到 20。這是測出來的，不是證出來的；為什麼是 4 左右沒有定論。
- 🔄 箱子大小在任一時刻有限，但看不到上界：箱子可以一層包一層。
- 🔄 格子數幾乎練不大：工作記憶訓練是練什麼進步什麼，不遷移。
- ⚠️ 「寬度就是天賦」→ 一半對。格子數有個體差異、部分天生，但差異很窄（3 格對 5 格）；高手和新手的巨大差距不從這裡來。
- 🔄 證據是西洋棋實驗（Chase & Simon 1973）：只有「箱子比較大」這個假設同時對得上兩欄。

| | 有限？ | 有界？ |
|---|---|---|
| 寬度（格子數） | 是 | 是 |
| 箱子大小（一格裝多少） | 是 | 看不到上界 |

| | 真實棋局看 5 秒 | 棋子隨機亂擺看 5 秒 |
|---|---|---|
| 實驗結果 | 高手記得遠比新手多 | 高手和新手幾乎一樣 |
| 假設「高手格子多」的預測 | 高手多 | 高手多（與實驗不符） |
| 假設「高手箱子大」的預測 | 高手多 | 一樣（與實驗相符） |

> 濃縮：人的格子數有界且練不大，箱子大小無界且練得動；高手贏在箱子，不在格子。

## 陷阱清單

- ⚠️ ❌ 人類把運算止步在加、乘、指數，之後的該開始定義了 → ✅ 早就定義了；人類卡的是算出值，不是定義 → 04 筆記「支線：超運算塔」段：整座塔由同一條遞迴規則生成，定義一步到位。
- ⚠️ ❌ 邏輯無限或趨近某個極限，人就碰不到那個真理 → ✅ 四類要分開：有限但很長（硬體問題）、無限多個案例（一個有限的證明蓋住）、極限（不用走完就能指認終點）、固定系統內不可證（人和 AI 都一樣）→ 弱點模式 1 的同型；AI 的優勢只落在第一類。
- ⚠️ ❌ AI 能無限制地疊加 → ✅ 更寬、更快的有限疊加 → 寬度有上界，可靠度的牆共用。
- ⚠️ ❌ AI 寬度這麼大，我應該一直被驚艷 → ✅ 寬度是它的工作檯，不是送到我這邊的量；它預設只給最常見的幾個，要開口要「沿哪幾條軸切」→ 訓練目標就是說出最不意外的下一個字；瓶頸在我這端的 4 格。
- ⚠️ ❌ 非生命、沒有目的，所以不可能主動傳達 → ✅ 現況是被動沒錯；主動缺的是目的，而目的可以借 → 把材質和接線方式混在一起（弱點模式 3）。
- ⚠️ ❌ 我天馬行空想得出很多，等於寬度變大 → ✅ 那是產量；寬度是同時握住幾個 → 一個接一個想，前面的已經不在場。（這條是導師前一輪沒把「寬度」和「產量」分開就說了對所引起的。）
- ⚠️ ❌ AI 的多樣性來自不同權重 → ✅ 權重固定，多樣性來自擲骰子 → 一張表、取一個字、一條路徑。
- ⚠️ ❌ 寬度就是天賦 → ✅ 天賦至少混了格子數（天生、窄、練不動）與箱子的品質（可練、專屬領域、無上界）→ 西洋棋實驗：亂擺的棋局高手不佔便宜。
