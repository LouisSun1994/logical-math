# 紐康姆悖論（Newcomb's Problem）：因果 vs 同源

- 來源：對話「介紹一下 Newcomb 悖論」→ 卡在「悖論在哪」→ 重建三次地基（四格表、你來當預測者、朋友喊話）→ 卡在「99% 準是什麼意思」→ 時間線 T0 / T1 / T2 → 復述確認
- 目前定位：趣談（決策理論的後設層）。不在主線階段路線圖內；它是「期望值」這個工具第一次碰到「兩條正確原則互相矛盾」的案例。

---

## 0. 一句話版本

**箱子在你選之前就封好了，所以選擇改不了它；預測者很準，所以你的選擇又幾乎「等於」它。兩箱派按「改不了」選，一箱派按「等於」選，兩邊的推理都推不倒，結論卻相反——這就是悖論。**

---

## 1. 概念樹骨架

```
紐康姆悖論（本篇）
├── 題目：兩箱、封箱規則、預測者 99% 準、資訊全公開
├── 四格表：結果固定，悖論在「怎麼讀這張表」
│   ├── 橫著比（優勢原則）→ 都拿，每一格都贏
│   └── 問落在哪一欄（期望值 + 條件機率）→ 只拿 B，總帳大贏
├── 「99% 準」的操作定義：猜的和做的，100 次對 99 次
│   └── 封箱規則 + 99% 準 串成一條鏈 → 只拿 B 的人 99% 有錢
├── 時間線 T0 封箱 / T1 進場 / T2 選擇
│   ├── 兩箱派：T2 改不了 T0（因果）
│   └── 一箱派：T2 與 T0 同源（同一個我的兩次露面）
└── 悖論的形狀：「每一格都贏」與「總帳卻輸」同時成立；至今無公認解

嫁接點：
- 期望值 = 結果 × 機率加總，接 01 筆記「機率基礎」段；這裡用的機率是「給定我這樣選」的條件機率，接 02 筆記「貝氏 vs 頻率派」段
- 「相關不等於因果，但相關可以當證據」接 07 筆記（指標 vs 目標）：那篇是相關被最佳化後崩壞，本篇反過來——相關穩固，問題是能不能拿它做決策
- 「兩條原則都對、但只能按一個來選」接趣談 01「數學的結構：三層並列」段：原則不是定理，兩條原則打架時沒有更高一層的裁判
- 「T2 不造成 T0，是同源」接弱點模式 3（物件 vs 性質）：「我的這一手」和「我是哪種人」是兩個層級，混在一起就會說出「T2 讓 T0 成立」
```

## 2. 題目與四格表

**種子**：紐康姆悖論 = 兩條各自成立的決策原則，在同一題上給出相反的答案。

題目：A 箱透明，1,000 元。B 箱不透明，100 萬或空。選項只有兩個：「只拿 B」或「A+B 都拿」。預測者在你進場前猜你會選哪個：猜「只拿 B」→ B 放 100 萬；猜「都拿」→ B 留空。它的歷史準確率 99%。箱子已封，你選的當下 B 裡面有什麼早已定案。你知道以上全部規則。

- 🔄 「只拿 B」不是限制，是兩個選項之一；題目問的是你要不要**放棄 A**。
- 🔄 選擇者知道全部規則，包括預測者存在與 99% 準；資訊沒有不對稱。不知道預測者 → 當然都拿 → 沒有第二個推理 → 沒有悖論。
- 🔄 四格表本身沒有爭議，悖論全在「怎麼讀」。
- ⚠️ 「只拿 B 的人是因為已經知道裡面有東西；都拿的人是因為覺得 B 大概率空」→ 不對。兩派都沒在猜 B。一箱派：放棄 A 這個動作就是會被放錢的那種人會做的事；兩箱派：不管 B 有什麼，多拿 A 就多 1,000，根本不需要猜 B。
- ⚠️ 把兩派想成「兩種人各自安心」→ 看不到矛盾。悖論是**同一個你**站在箱子前，腦中同時跑出兩個推理，兩個都反駁不了。

| | B 有 100 萬 | B 是空的 |
|---|---|---|
| 只拿 B | 1,000,000 | 0 |
| A+B 都拿 | 1,001,000 | 1,000 |

| 讀法 | 怎麼讀 | 結論 |
|---|---|---|
| 橫著比（優勢原則，dominance） | 不管哪一欄，「都拿」那列永遠多 1,000；箱子已封，我搬不動自己的欄位 | 都拿 |
| 問我會落在哪一欄（期望值） | 只拿 B 的人 99% 在左欄；都拿的人 99% 在右欄 | 只拿 B |

**濃縮**：四格表固定；橫著比是都拿，問落在哪一欄是只拿 B。

## 3. 「99% 準」是什麼意思

**種子**：99% 準 = 預測者猜的和你實際做的，100 個玩家裡有 99 個一樣。

- 🔄 「猜中」的定義：猜只拿 B 而你真的只拿 B，或猜都拿而你真的都拿。
- 🔄 這個數字來自封箱規則 + 準確率串成的鏈：你實際只拿 B → 99% 它猜的也是只拿 B → 猜只拿 B 就放了 100 萬 → 你打開 99% 有錢。反過來：你實際都拿 → 99% 它猜都拿 → 留空 → B 99% 是空的。
- 🔄 「只拿 B 有錢」不是預測者偏心一箱派，是**封箱規則**偏心一箱派（遊戲設計）；預測者只負責讓「猜的」和「你做的」幾乎一樣。
- 🔄 它不是三件事：不是預測者控制你；不是你選完它才放錢；不是「B 有錢的機率是 99%」——B 有錢的機率取決於你是哪種人。
- 🔄 預測者是誰、怎麼做到的（外星人、超級電腦、腦部掃描跑模擬），題目故意留白；悖論只需要「先封箱」+「很準」兩個條件。追問「怎麼做到」會把你推向某一派：想成跑模擬 → 傾向一箱；想成看歷史資料猜 → 傾向兩箱。
- 🔄 預測者決定的不是箱子，是「你的選擇」與「箱子內容」之間那條**沒有因果的相關線**，以及它有多緊（99%）。拿掉它（擲硬幣封箱）→ 相關消失 → 兩種讀法都說都拿 → 悖論消失。
- ⚠️ 沒弄清「99% 準」的操作定義，整題成霧——這是這條線真正卡住的點，不是悖論本身。

| 你實際選了 | 預測者猜對（99%） | 預測者猜錯（1%） |
|---|---|---|
| 只拿 B | B 有錢 → 拿 1,000,000 | B 空 → 拿 0 |
| A+B 都拿 | B 空 → 拿 1,000 | B 有錢 → 拿 1,001,000 |

準確率 p 當變數，兩選項的期望值（M = 100 萬、k = 1,000）：

| p | 只拿 B：p·M | 都拿：k + (1−p)·M | 該選 |
|---|---|---|---|
| 1.00 | 1,000,000 | 1,000 | 只拿 B |
| 0.99 | 990,000 | 11,000 | 只拿 B |
| 0.50 | 500,000 | 501,000 | 都拿（兩讀法一致，悖論消失） |
| 0.00 | 0 | 1,001,000 | 都拿 |

打平點 p = ½ + k/(2M) ≈ 0.5005。

**濃縮**：99% 準 = 你的選擇幾乎能「猜出」箱子裡有什麼，雖然你的選擇改不了它。

## 4. 時間線：因果 vs 同源

**種子**：T0 封箱 → T1 進場 → T2 選擇；悖論卡在「T2 和 T0 是什麼關係」。

```
T0  預測者看完你，猜好，封箱。B 有沒有錢，此刻定案。
T1  你走進房間，站在箱子前。
T2  你選。
```

- ✅ 兩箱派：T0 就已經決定有或沒有了，T2 這一手改不了 T0，所以當然都拿——T2 唯一能影響的就是多不多拿那 1,000。
- ✅ 一箱派：只要我是一箱派的人，我當然在 T2 選只拿 B，因為 T2 選 B 的人，T0 就是被讀成會這樣的人。
- ✅ 悖論：兩箱派的 T2 觀點是對的，一箱派的 T0 觀點也是對的，兩個都對但結論相反。
- ✅ 都拿的人在 99% 準的預測下只拿到 1,000——而且在打開空箱的當下，他的推理仍然沒有錯（「如果我剛才只拿 B，我會拿到 0」是真話）。「推理正確」和「結果最差」穩定綁在一起，才是悖論。
- 🔄 讓兩箱派直覺站起來的版本：有人告訴你「B 的 100 萬我剛親眼看到放好了」，你會留下桌上的 1,000 不拿嗎？留下它 B 不會更滿。兩箱派說：封箱那一刻起情況就跟這一模一樣，只差你沒親眼看到。
- 🔄 一箱派對兩箱派的反駁：「你的推理是對的，但會做這種推理的人就是會遇到空箱；你該選的不是箱子，是你是哪種人。」兩箱派回：「『我是哪種人』這張牌在 T0 已經打掉了，T2 沒有牌可打。」到這裡兩派互相推不倒。
- 🔄 兩派對應的學派：因果決策論（causal decision theory, CDT）→ 都拿；證據決策論（evidential decision theory, EDT）→ 只拿 B。至今沒有公認解。
- 備註（用詞）：「T2 選 B 讓 T0 才成立」→ 不精確。T2 不造成 T0（時間不倒流，兩箱派會立刻反駁）；準確說法是 T2 和 T0 是**同一個我的兩次露面**——不是造成，是同源。這一字之差是一箱派立場能不能站住的關鍵。

| 派別 | 看 T2 與 T0 的關係 | 承認什麼算數 | 結論 | 結果（99% 準） |
|---|---|---|---|---|
| 兩箱派 | T2 改不了 T0 | 只有「改變」算數 | 都拿 | 99% 拿 1,000 |
| 一箱派 | T2 與 T0 同源 | 「同源」也算數 | 只拿 B | 99% 拿 1,000,000 |

**濃縮**：兩箱派看因果（T2 改不了 T0），一箱派看同源（T2 和 T0 是同一個我）；兩個都對，但只能按一個來選。

## 5. 類比與失效點

- 🔄 快取：預測者在你發請求前，就用「預測你會發什麼請求」把回應預先寫進快取。你發的請求改不了快取內容，但你發什麼請求，幾乎決定你會命中哪份快取。
- 🔄 反作弊：系統依你歷史行為預判你會不會作弊，提前決定給不給你進高額房。**失效處**：真實系統沒有 99%，而且你知道被預測後可以刻意改行為；紐康姆的設定是連「刻意」也在預測範圍內——這正是悖論成立的前提，拿掉它悖論就消失。

**濃縮**：類比能講「先封、很準」，講不了「連你想繞過它也被算進去」。

## 陷阱清單

- ❌ 以為「只能選 B」是一條限制 → ✅ 它是兩個選項之一，題目問的是要不要放棄 A → 為什麼：封箱規則獎勵的是「放棄 A」這個動作，看不到這點就看不到一箱派在賭什麼。
- ❌ 兩派都在「猜 B 有沒有錢」 → ✅ 兩派都沒在猜；兩箱派「不管 B 有什麼多拿就多」，一箱派「放棄 A 的人才會被放錢」 → 為什麼：把心理預期加進去，兩派就變成兩種各自安心的人，矛盾消失，悖論也跟著消失。
- ❌ 「99% 準」= B 有錢的機率 99% → ✅ 它是「猜的 = 做的」的比例；B 有錢的機率取決於你是哪種人 → 為什麼：無條件機率和條件機率混用，是 02 筆記「貝氏 vs 頻率派」段的老問題換了衣服。
- ❌ 悖論 = 都拿的人拿得少 → ✅ 悖論 = 都拿的人拿得少**而且推理仍然沒錯** → 為什麼：拿得少不奇怪，「每一格都贏」卻「總帳輸」才矛盾。
- ❌ 「T2 選 B 讓 T0 有錢」 → ✅ T2 不造成 T0，T2 與 T0 同源 → 為什麼：說成「造成」會被「時間不倒流」一擊打倒；一箱派真正的立場是「我的這一手」和「我是哪種人」是同一件事的兩次露面（用詞問題，記為備註）。

## 心智模型總結

```
四格表固定，悖論在讀法
  橫著比（因果）：都拿，每一格都贏
  問落在哪一欄（條件機率）：只拿 B，總帳大贏
燃料只有兩條：先封箱 + 很準（p 降到 0.5 悖論消失）
時間線：T0 封箱 → T2 選擇
  兩箱派：T2 改不了 T0（只有「改變」算數）
  一箱派：T2 與 T0 同源（「同源」也算數）
兩個都對 → 只能按一個來選 → 沒有裁判 → 悖論
兩箱派窮得有道理，一箱派富得沒道理
```
