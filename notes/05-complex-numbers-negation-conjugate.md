# 複數的幾何：負號是旋轉、共軛是一面鏡

## 0. 一句話版本

**複數乘法只會旋轉、不會鏡射；負號是轉 180°（兩面鏡子），共軛是一面鏡子（鏡在實軸、翻虛部），所以共軛不是乘法、需要自己的符號。**

---

## 1. 概念樹骨架

```
複數乘法 = 長度相乘、角度相加（種子 J）
 └─ 乘法永遠是旋轉
     ├─ 負號 = 乘 −1 = 轉 180° = 兩個分量都翻
     │   ├─ 180° 是唯一讓實數乘法封閉的非平凡相位
     │   └─ i = 半個負號（轉 90°）
     ├─ 鏡射不是旋轉 → 不是乘法 → 共軛需要獨立符號
     │   ├─ 共軛 z̄：鏡在實軸，翻虛部，相位 −θ
     │   └─ 負共軛 −z̄：鏡在虛軸，翻實部，相位 180°−θ，無標準專名
     └─ 數線（一維）vs 平面（二維）
         └─ 數線上負號是鏡射（無中間態）；進平面才變旋轉（有中間角度）
```

嫁接點：「有沒有中間態」接 04 筆記 I 段的連續／離散判準；「相位屬乘法不屬加法」是後面向量段（06 筆記）區分三種積的起點。

## 2. J. 數系結構（複數）

**種子：複數乘法 = 長度相乘、角度相加，所以乘法永遠是旋轉。**

- ✅ 負號 = 乘以 −1 = 轉 180° = 實部虛部都翻；獲得/損失同長度、反相位。
- ✅ 180° 是唯一讓實數乘法封閉的非平凡相位（2θ ≡ 0 mod 360°）；i = 半個負號；複數是把角度放開的推廣，代價是失去順序 <。
- ✅ 數線上負號是鏡射（無中間態），進平面才是旋轉；相位屬乘法不屬加法。
- ✅ 共軛 z̄ = 把 i 換成 −i = 以實軸為鏡、翻虛部。實數分不出 i 與 −i，所以實係數造的等式對共軛免疫（實根成對）；z·z̄ 抵消相位留長度平方；除法靠共軛把分母變實數。
- ✅ 鏡射不是乘法（左手變右手），所以共軛需要獨立符號。
- ✅ 以虛軸為鏡、只翻實部 = −z̄，不尊重乘法（f(1)=−1），無標準專名（工程偶稱 paraconjugate）。
- ✅ 相位觀點：負號 θ+180°、共軛 −θ、負共軛 180°−θ；只有負號是「加常數」。
- ⚠️ 把「鏡子在哪條軸」與「哪個分量被翻」對調。規則：鏡子在實軸 → 翻虛部。
- ⚠️（反覆出現）把「只翻實部」當成負號。檢驗法：拿虛部 ≠ 0 的例子試，實數例子看不出差別。
- 備註（非混淆）：「鏡像」一詞我泛指對稱、可做兩次；需守的線只有「負號 = 兩面鏡子，不是一面」。

### 為什麼偏偏是 180°

```
要求：實數乘實數還是實數 → 相位轉兩次要回到 0
      2θ ≡ 0 (mod 360°)
解：  θ = 0°（平凡，乘正數）或 θ = 180°（負號）
放開這個要求 → 任何角度都可以 → 複數
代價：平面上沒有自然的「誰大誰小」→ 失去順序 <
```

### 手填表：三種操作，三個相位

| 操作 | 幾何 | 鏡子在哪 | 翻哪個分量 | 相位 θ 變成 | 是乘法嗎 | 符號 |
|---|---|---|---|---|---|---|
| 負號 | 轉 180° | （兩面鏡子的合成） | 實部、虛部都翻 | θ + 180° | 是（乘 −1） | −z |
| 共軛 | 一面鏡 | 實軸 | 翻虛部 | −θ | 否 | z̄ |
| 負共軛 | 一面鏡 | 虛軸 | 翻實部 | 180° − θ | 否 | −z̄（無專名） |

只有負號是「加常數」；另外兩個都帶著 −θ，所以它們改變的是「轉向」而不是「轉多少」。

### 極端案例測試（這一段實際用過的驗證法）

| 測試用的 z | 負號 −z | 共軛 z̄ | 負共軛 −z̄ | 看得出差別嗎 |
|---|---|---|---|---|
| 實數（虛部 = 0） | −a | a | −a | 負號與負共軛分不開 → 退化例子 |
| 純虛數（實部 = 0） | −bi | −bi | bi | 負號與共軛分不開 → 退化例子 |
| 虛部、實部都非零 | −a − bi | a − bi | −a + bi | 三個全部分開 → 這才是有效測試 |

### 共軛為什麼有用

| 用途 | 機制 |
|---|---|
| 實根成對 | 實數分不出 i 與 −i，所以實係數等式對「把 i 換成 −i」免疫 |
| 取長度 | z·z̄：相位 θ + (−θ) = 0，只剩長度平方 |
| 除法 | 分母乘自己的共軛 → 變實數 → 可以直接除 |

一句濃縮：**乘法只會轉、不會翻；要翻就得離開乘法，所以共軛有自己的符號。**

## 3. 對話脈絡（憑摘要）

- 起點是自己提出的直覺：負號是複數平面上的相位旋轉。被確認為結構上正確：乘 −1 = 轉 180°，是唯一讓實數乘法封閉的非平凡相位。
- 進入共軛後反覆把「鏡子在哪條軸」與「哪個分量被翻」對調，提出過數個錯誤版本（例：共軛 = 以虛軸為鏡翻實部；負號 = 以虛軸為鏡）。每次都用「鏡在一軸、翻另一分量」與「負號是兩面鏡的合成、乘法只能轉不能翻」校正。
- 一次「一半對」的判定，事後釐清是**用詞**（「鏡像」隱含單一鏡射）而非實質錯誤。這促成教學規則新增一條：實質主張與用詞分開判，「不對」只留給實質錯誤。
- 問「以虛軸為鏡、只翻實部」有沒有標準名字：沒有，因為它不尊重乘法（f(1) = −1）；工程上偶稱 paraconjugate。
- 結尾要求整份 instructions 重寫，J 段與「實質 vs 用詞」規則一併收進 2026-10-05 版。

## 陷阱清單

1. ❌ 共軛 = 以虛軸為鏡 / 翻實部 → ✅ 共軛的鏡子在實軸，翻的是虛部 → 為什麼：鏡子在哪條軸，被翻的是**另一個**分量；「軸 vs 分量」是這一段的 type error 主型。
2. ❌（反覆出現）只翻實部就是負號 → ✅ 只翻實部是 −z̄（鏡在虛軸）；負號要兩個分量都翻 → 為什麼：負號是兩面鏡子的合成（= 旋轉），一面鏡子永遠不是乘法。檢驗法：拿虛部 ≠ 0 的例子試，實數例子看不出差別（弱點模式 2：退化例子測不出兩個操作的差別）。

備註（用詞，非混淆）：「鏡像」我泛指對稱、可做兩次；要守的線只有「負號 = 兩面鏡子，不是一面」。

## 心智模型總結

```
乘法     ← 長度相乘、角度相加 → 永遠是旋轉
負號     ← 轉 180° = 兩面鏡 = 兩個分量都翻；唯一讓實數封閉的非平凡相位
i        ← 半個負號（90°）；放開角度 = 複數；代價 = 失去 <
共軛     ← 一面鏡在實軸、翻虛部、相位 −θ；不是乘法 → 要獨立符號
−z̄       ← 一面鏡在虛軸、翻實部、180°−θ；不尊重乘法 → 無專名
測試     ← 一定拿實部虛部都非零的例子，退化例子分不出三者
```
