## 0. 一句話版本

## 2. 應用（RTP / 獎池）

**種子：總派彩 = Σ（每小循環金額 × 期望觸發次數）（Wald）。**

- ✅ 大/小循環：K = Σ gᵢ·E[Mᵢ]；M 隨機時 rate target vs total target 二選一。
- ✅ λ(t) 非平穩 → operational time；巢狀結構對應 Haar/小波；成熟領域是 budget pacing。
- ✅ 籤筒（不放回）是變異數縮減裝置。
- ✅ MySQL CHECK `MOD(x*10,5)=0` ⟺ 0.5 增量。

（來自 02 筆記「假設檢定」段）
- ✅ 浮動倍率派彩是重尾，RTP 收斂速度取決於倍率上限與觸發率。

### 記號（最後才出現）

```
K = Σᵢ gᵢ · E[Mᵢ]
    gᵢ    ：第 i 種小循環每次派出的金額
    Mᵢ    ：大循環內第 i 種小循環被觸發的次數（隨機）
    E[Mᵢ] ：它的期望次數
```

Wald 的要點：次數 M 是隨機的也沒關係，期望值可以直接拆成「單次金額 × 期望次數」。

### 手填表：M 隨機時只能選一個目標

| 目標 | 固定什麼 | 浮動什麼 | 適合 |
|---|---|---|---|
| rate target | 每次觸發的派出比率 | 一個大循環的總派彩 | 想守 RTP |
| total target | 一個大循環的總派彩 | 每次觸發的派出比率 | 想守預算 |

兩個都想固定 ⟹ 需要 M 不隨機，但 M 本來就是隨機的，所以二選一。

### λ(t) 非平穩：換一條時間軸

```
牆上時鐘  t      ：觸發率 λ(t) 隨時段起伏（尖峰／離峰）
operational time ：把「累積的期望觸發數」當時間，在這條軸上 λ 變成常數
巢狀結構         ：日內 → 週內 → 月內的起伏，一層套一層 ↔ Haar／小波的多尺度分解
成熟領域         ：廣告投放的 budget pacing 已經把這套做熟
```

### 籤筒：不放回是刻意的設計

| | 放回（獨立抽） | 不放回（籤筒） |
|---|---|---|
| 每次抽中機率 | 固定 | 隨已抽結果變動 |
| 一輪結束時的總派出 | 有變異 | 被釘死 |
| 用途 | 單次公平 | 總量可控 → 變異數縮減裝置 |

### 資料層的小工具

```sql
CHECK (MOD(x * 10, 5) = 0)   -- ⟺ x 只能是 0.5 的整數倍
```

一句濃縮：**Wald 把「隨機次數的加總」拆成「金額 × 期望次數」，剩下的設計問題都是在決定哪個量要被釘住。**

## 陷阱清單

本段沒有 ⚠️ 條目。與這一段相關、記在別篇的 ⚠️：

1. ❌（01 筆記「大數法則 vs 中央極限定理」段）「一個算出來的 RTP」有分佈 → ✅ 有分佈的是抽樣前的隨機變數，算出來的數是一次實現 → 為什麼：物件 vs 物件性質。
2. ❌（02 筆記「尾巴分類」段）把重尾當成「偶爾有大值」 → ✅ 重尾是危險率下降的結構性質 → 為什麼：浮動倍率派彩的收斂慢，根源在尾巴結構，不在運氣。

## 心智模型總結

```
K          ← Σ gᵢ·E[Mᵢ]（Wald：隨機次數可直接取期望）
二選一     ← rate target 或 total target，M 隨機時不能兩個都釘
非平穩 λ   ← 換到 operational time；多尺度 ↔ 小波；參考 budget pacing
籤筒       ← 不放回 = 釘住總量 = 變異數縮減
重尾派彩   ← 收斂速度 = f(倍率上限, 觸發率)
下一步     ← Poisson 過程（觸發的隨機時間結構）→ 馬可夫鏈（獎池狀態機）
```
