# 梯度與訓練的一步：地形不動、人在動（Gradient & One Step of Training）

- 記錄日期：2026-10-22 → 2026-10-29
- 來源：對話「梯度教學」（起因：動手訓練權重後發現不理解梯度，只是跑程序、出新權重、評測）
- 目前定位：支線。從 K 段（06 筆記的向量／內積／矩陣線）延伸出的「梯度 → 訓練一步」線；反向傳播與交叉熵留待課綱另開。

---

## 0. 一句話版本

**訓練 = 在權重空間裡，從一份 checkpoint 出發，反覆讀出損失地形在腳下的坡度（梯度），往反方向走一小步，直到驗證 loss 不再出現新低。**

---

## 1. 概念樹骨架

```
點 w（checkpoint = n 個參數各取定一值）
 └─ 地形 L(w)（由架構 M、資料、量尺 ℓ 三個不變零件組成；輸出一個實數）
     ├─ 偏微分 ∂L/∂wᵢ：釘住其他鈕、只動第 i 個，「高度的變化率」= 高度差 ÷ 該參數的 Δ（一個數）
     │    └─ 嫁接：一變數導數（斜率、變化率）的多變數版；n = 1 退化回導數
     ├─ 梯度 ∇L(w)：n 個偏微分排成一支向量；值是向量、單位是「L 每 w」
     │    ├─ 讀法一：靈敏度表（每格 = 該鈕的邊際效果）
     │    ├─ 讀法二：權重空間裡一支箭，指向 L 上升最快處，長度 = 陡度
     │    │    └─ 嫁接 K 段內積：ΔL ≈ ∇L·Δw，同向極大、反向極小 → 兩種讀法是同一物件
     │    └─ 等高面（n−1 維）⊥ 梯度 ← 嫁接 K 段「外積給法向量」
     ├─ 一步 Δw = −η∇L（位移向量；負號選下坡、η 把率換成量）
     │    ├─ 新 checkpoint = w + Δw
     │    ├─ 單位：[∇L] = L/w、[η] = w²/L、相乘剩 w = [Δw]；負號無單位
     │    ├─ 保證：ΔL ≈ −η|∇L|² ≤ 0（步夠小時不上升）
     │    └─ 最陡 ≠ 最短（狹谷鋸齒）
     ├─ 向上／向下：選 ± 讓函數值升或降，意義由該函數決定
     │    └─ 嫁接 F 段：降交叉熵 = 升對數概似（同一梯度差一個負號）
     └─ 停止：看 L 的值不再出現新低（patience 規則），不是 ∇L = 0、不是 L = 0
          ├─ 嫁接 G 段「探索資料不能再拿來驗證」→ 驗證集 / early stopping
          └─ 過擬合：資料 = 機制 + 雜訊；L_train 續降、L_val 回升 → 退回最佳存檔，不是梯度向上
               └─ 嫁接 A 段「母體 vs 樣本」
```

嫁接點（段落代號對應筆記：A、B → 01；F、G → 02；K → 06 向量線，沿用對話中的代號）：
- B 段「均值是平方誤差的最小化點」：那是 n = 1 的梯度為零條件；最小點 = 答案、最小值 = 答案的品質（變異數）。
- B 段「為什麼平方不用絕對值」：那整段其實是在**選量尺 ℓ**——換量尺、地形變、最低點搬家。
- K 段「矩陣是線性規則的紀錄表」：切平面是線性規則，梯度是它的紀錄表；向量輸出時升級為 Jacobian 矩陣。
- K 段「梯度爆炸／消失」（🔄）：反向傳播 = 規則接力的斜率版，本篇未展開。

## 2. 點與地形

**種子：一個點本身沒有坡度；坡度是地形在那一點的性質。**

- ✅ 權重空間裡一個點 w = 一份權重檔（checkpoint）= n 個參數各取定一個值。訓練 = 一連串的點。
- ✅ checkpoint 本身沒有梯度；要有 L 出現才有。梯度是 **L 在 w 的性質**，不是 w 的性質。
- ✅ L 是「這份權重答錯多少」的量尺：輸入 w、輸出一個實數。它是你對「好」的定義，先於訓練存在。
- ✅ M 的架構不變，變的是帶進去的參數值 w。
- 🔄 L 由三個不變零件組成：架構 M、資料 D、誤差量尺 ℓ；L(w) = 對所有資料取 ℓ 的平均。w 是唯一變數。
- 🔄 一張地形上有無數個點；每個點有一個 L **的值**（高度），不是有一個 L。另一面：同一個 checkpoint 換地形（換資料或 ℓ），梯度就不同。
- 🔄 L 是量尺，**L 的最小點**才是目標。平方誤差版的 L 就是 B 段 RMS 做到第二步（平方→平均），把 X 換成「預測 − 答案」；但 RMS 是一個數，L 是函數。
- 🔄 ℓ 是設計決策：平方誤差（連續值）、交叉熵（機率分佈，LLM 用它）。
- 🔄 pre-training 與 fine-tuning 是同一機制，差在起點 w、資料、規模；沒有繞過 L 直接訓練 M 這回事。
- 🔄 mini-batch 使每步看到的是地形的近似，略有抖動，結構不變。

對照：地形從零件長出來。M(x; w) = w·x，資料 (1,2), (2,3), (3,5)。

| w | 三個預測 | 三個誤差 y − 預測 | 平方誤差 L | 絕對值誤差 L |
|---|---|---|---|---|
| 1 | 1, 2, 3 | 1, 1, 2 | (1+1+4)/3 = 2 | (1+1+2)/3 = 4/3 |
| 1.5 | 1.5, 3, 4.5 | 0.5, 0, 0.5 | (0.25+0+0.25)/3 = 1/6 | (0.5+0+0.5)/3 = 1/3 |
| 2 | 2, 4, 6 | 0, −1, −1 | (0+1+1)/3 = 2/3 | (0+1+1)/3 = 2/3 |

同資料同架構，換 ℓ 就換地形：表上三個 w 裡兩種量尺都是 1.5 最低，但高度與形狀不同，真正的最低點也不在同一處（平方誤差約 1.64、絕對值誤差約 1.67）。每一列是一個 checkpoint 的高度，三列合起來才是地形的一小段。

對照：一步之內誰動誰不動。

| 物件 | 固定／變動 |
|---|---|
| 訓練資料 x | 固定 |
| 權重 w | 變動（唯一被推的） |
| 地形 L 的形狀 | 固定 |
| ∇L 的值 | 變動（跟著 w） |
| 模型 M 的行為 | 變動（跟著 w） |

**濃縮：點是座標、L 是地形、梯度是地形在座標的坡度；地形不動，人在動。**

## 3. 偏微分與梯度

**種子：導數回答的唯一問題是「動一點會怎樣」；梯度是對 n 個鈕各問一次，n 個答案排成一列。**

- ✅ 偏微分 = 釘住其他鈕（代成常數）、只動一個，剩下那個變數的**普通導數**。相減的是**高度**（輸出），不是分量。
- ✅ 梯度一格 = 高度的變化率 = 高度差 ÷ 該參數的 Δ。分子高度差、分母鈕的動量。
- ✅ 高度的變化率 ≠ 高度差（量 vs 率）；「高度差的變化率」是二階（曲率）。
- ✅ 梯度 = 導數（斜率、變化率）的多變數版：每個參數各一個斜率排成向量；n = 1 時退化回導數。
- ✅ 為什麼是向量：n 個鈕各有自己的率，一個數無法分辨是哪個鈕靈敏。
- ✅ 梯度記的是 n 條「某個輸入 → 輸出」的變化率；輸入之間沒有任何關係被記錄。
- ✅ 梯度是變化率，單位與 Δw 不同：值是向量，單位是「L 每 w」（分子不能省），整支共用一個單位。
- ✅ 一個點有 n 個偏微分、**一支**梯度；n 是分量數不是梯度數。
- 🔄 n 個偏微分共享同一個錨點 w、同一份資料、同一個 L，只換被動的鈕。換點全部重算，所以嚴格說只有「函數在某點的梯度」。
- 🔄 每個量 = 數值 + 單位。向量／純量是數值層的事；單位永遠只有一個，單位裡的斜線記錄來源、不做除法、沒有值。

對照：對 x 的偏微分，L = x² + 3y，站在 (1, 2)。

| 動作 | 位置 | 高度 |
|---|---|---|
| 出發 | (1, 2) | 7 |
| 只往 x 走 0.1，y 不動 | (1.1, 2) | 7.21 |
| 高度差 | | 0.21 |
| ÷ 步長 0.1 | | 2.1 |
| 步長 → 0，收斂到 | | **2** = ∂L/∂x |

整張表 y 永遠 = 2：它是常數不是變數。等價做法：代 y = 2 得 g(x) = x² + 6，普通導數 2x，代 x = 1 得 2。

對照：量 vs 率。L = x² + 3y + z，在 (1, 2, 5)，每次只動一個鈕 0.1。

| 實驗 | 高度差 ΔL（量） | ÷ 0.1 → 第 i 格（率） | 極限 |
|---|---|---|---|
| 動 x | 0.21 | 2.1 | 2 |
| 動 y | 0.30 | 3 | 3 |
| 動 z | 0.10 | 1 | 1 |

步長改 0.01 時：高度差變 0.0201 / 0.03 / 0.01（全縮 10 倍），率仍是 ≈ 2 / 3 / 1。**量隨步長變、率不變**，所以梯度是地形的性質，不是實驗的性質。∇L(1,2,5) = (2, 3, 1)。

對照：階數。

| 說法 | 指的是 | 階數 |
|---|---|---|
| 高度 | L 的值 | 0 |
| 高度的變化率 | 梯度一格 | 1 |
| 高度差的變化率 | 曲率（Hessian） | 2 |

**濃縮：偏微分是「其他鈕代成數字後的普通導數」，減的是高度；n 個率排成向量就是梯度；n = 1 時它就是導數。**

## 4. 梯度的意義：靈敏度表與最陡方向

**種子：梯度的第一意義是靈敏度清單，「最陡」是從清單推出來的第二層結論。**

- ✅ 「某種條件下的最佳一步」：條件 = 步長固定，最佳 = 等長步裡 ΔL 變化最多。
- 🔄 讀法一（看分量）：第 i 格 = 只動第 i 個鈕、L 每單位變多少（靈敏度、邊際效果）。
- 🔄 讀法二（看整支）：箭尾釘在 w、箭身畫在權重空間（地板）上，指向 L 上升最快方向，長度 = 陡度；與箭垂直的方向 L 不變（等高線）。
- 🔄 兩種讀法是同一支箭：ΔL ≈ ∇L·Δw（切平面的可加性 = 內積），步長固定時內積在同向極大、反向極小，所以靈敏度表排成的箭自動是最陡方向。沒有第二個物件。
- 🔄 切平面 n 維、梯度 n 個分量、等高面 n−1 維、梯度是等高面的法向量。n−1 只出現在等高面。
- 🔄 高維特性：[1,1,…,1] 長度 √n——鈕越多、同樣靈敏度、坡越陡。高維平地多為鞍點，不是谷底。
- 🔄 鈕單位不一時分量不能直接比大小（尺度問題）；LLM 權重無因次，無此麻煩。
- 備註：靈敏度、敏感度、陡度、邊際效果、力（位能的負梯度）= 梯度的業內俗名，物件相同；∇ 到哪都叫梯度。

對照：等長的步比 ΔL。L = x² + 3y，在 (1,2)，∇L = (2, 3)，所有步長度 0.1。

| 步 Δw | ΔL ≈ ∇L·Δw |
|---|---|
| (0.1, 0) 只動 x | 0.2 |
| (0, 0.1) 只動 y | 0.3 |
| (0.071, 0.071) 平分 | 0.355 |
| (0.055, 0.083) 按靈敏度比例 2:3 | **0.361**（最大 = 0.1·√13） |
| (0.083, −0.055) 與 ∇L 垂直 | 0（走在等高線上） |
| (−0.055, −0.083) 按比例反向 | **−0.361**（最小，梯度下降選的） |

按比例勝平分的那一點點（0.361 vs 0.355），就是內積同向極值的全部。

對照：維度。

| 物件 | 住在幾維／幾個分量 |
|---|---|
| 權重空間 | n |
| 切平面 | n |
| 梯度 | n 個分量 |
| 等高面 | n−1 |
| L 的值 | 1 |

對照：RTP 調參就是梯度。三個鈕（小獎賠率、大獎觸發率、免費遊戲次數），∇RTP = (0.8%, 2.5%, 0.3%)，改動總長約 0.3。

| 改法 (Δw₁, Δw₂, Δw₃) | 預測 ΔRTP = 0.8Δw₁ + 2.5Δw₂ + 0.3Δw₃ |
|---|---|
| (−0.3, 0, 0) 全押 w₁ | −0.24% |
| (0, −0.3, 0) 全押 w₂ | −0.75% |
| (0, 0, −0.3) 全押 w₃ | −0.09% |
| (−0.09, −0.28, −0.03) 按梯度比例 | **≈ −0.78%** |

把力氣按反應程度分配給各鈕，效果最大——「最陡」的白話版，不需要山。失效點：三個鈕單位不同，「總長 0.3」嚴格說不能直接比。

對照：讀一支梯度。

| 梯度 | 意義 |
|---|---|
| [1, 1, …, 1] | 所有鈕一樣靈敏，各轉 +1 L 各升 1；長度 √n |
| [0, 0, …, 0] | 平地，訓練停（谷底、山頂或鞍點） |
| [5, 0, …, 0] | 只有第一個鈕有影響，其他鈕動了 L 不變 |
| [1, −1, 1, −1, …] | 奇數鈕要往負轉、偶數鈕要往正轉 |

**濃縮：梯度是各鈕的邊際效果清單；「最陡」只是「固定預算按靈敏度比例分配效率最高」的別名，由內積保證。**

## 5. 一步：Δw = −η∇L

**種子：梯度是率、步是量；率乘 η 才成量，負號選下坡。**

- ✅ Δw 是 checkpoint 要怎麼移動的位移向量；w_new = w_old + Δw 是新 checkpoint。Δw 不是新檔。
- ✅ ∇L 是讀數（地形決定），Δw 是步（你決定）；梯度下降刻意取 Δw = −η∇L，兩者仍是不同物件。
- ✅ ∇L 給 Δw 的方向（翻面後）與各鈕的相對比例；η 是係數，給步長。
- ✅ Δw = −η∇L 是降（梯度下降，訓練用）；+η∇L 是升。
- 🔄 推導只給 Δw ∝ −∇L（正比於，倍率留白），比例常數推不出來，是你選的。
- 🔄 代回驗證：ΔL ≈ ∇L·(−η∇L) = −η|∇L|² ≤ 0——步夠小時這一步保證不上升。這是「訓練為什麼有價值」的數學內容。
- 🔄 負號：每格讀的是「鈕往 + 轉、L 怎麼變」，你要 L 降，所以**正格往負轉、負格往正轉**；n 格各自反號疊起來 = 整支乘 −1。負號無單位、不隨 w 變、是規則不是量。
- 🔄 η：念「艾塔」（eta），學習率（learning rate，程式碼裡的 lr，有些書寫 α）。你設的正數，n 個鈕共用，整支箭等比例縮放、方向不變。單位 [w]²/[L] 只是讓「率 × η = 量」成立的配額，不要替它找意義；想要意義就改記成時間步（梯度 = 速度，η = Δt，Δw = 位移）。LLM 裡 w、L 無因次，所以 lr 是純數。
- 🔄 η 太大跨出切平面近似範圍（loss 不降反升、震盪）；太小走不完；η = 0 訓練死掉。調 lr 調的是「切平面近似要在多大範圍內成立」。
- 🔄 最陡 ≠ 最短：每步最陡走出的路在狹谷裡鋸齒；動量法、Adam 在修這個缺陷（等於替每個鈕配自己的 η）。
- 🔄 換 checkpoint 會變的：高度、∇L、Δw；不變的：地形 L、η、負號。
- 備註：∝ 念「正比於」；[x] 念「x 的單位」。

對照：負號與 η 各修一個錯。L = x² + 10y²（低點 (0,0)），站在 (10, 1)，L = 110，∇L = (20, 20)。

| 公式 | Δw | 新點 | 新 L | 結果 |
|---|---|---|---|---|
| Δw = ∇L | (20, 20) | (30, 21) | 900 + 4410 = 5310 | 升：沒負號，往上坡走 |
| Δw = −∇L | (−20, −20) | (−10, −19) | 100 + 3610 = 3710 | **也升**：方向對、步長 28 是坡度數字不是距離，甩過低點 |
| Δw = −0.05·∇L | (−1, −1) | (9, 0) | 81 | 降：方向對、步長 1.4 在近似有效範圍內 |

Δw = ∇L 錯兩處，Δw = −∇L 只修一處。

對照：逐格反號。∇L = [1, −2, 3, −4]。

| 鈕 | 格子值 | 鈕往 + 轉 1，L 變 | 要 L 降，這個鈕往 | 反號後 |
|---|---|---|---|---|
| w₁ | +1 | 升 1 | − | −1 |
| w₂ | −2 | 降 2 | + | +2 |
| w₃ | +3 | 升 3 | − | −3 |
| w₄ | −4 | 降 4 | + | +4 |

沒有一格用「終點」決定；每格只看自己的正負。負格反號後變正：**下降 ≠ 全部減小**。驗證（η = 0.1）：走 +η∇L，ΔL ≈ 0.1·(1+4+9+16) = +3；走 −η∇L，ΔL ≈ −3。

對照：一步算到底。L = x² + 3y，w_old = (1, 2)，η = 0.1。

| | 值 |
|---|---|
| ∇L(w_old) | (2, 3) |
| Δw = −η∇L | (−0.2, −0.3) |
| w_new = w_old + Δw | (0.8, 1.7) |
| L(w_old) | 7 |
| L(w_new) | 0.64 + 5.1 = 5.74 |
| 預測 ΔL = −η\|∇L\|² | −0.1 × 13 = −1.3（實際 −1.26） |

對照：η 的大小只縮放步長，方向不變。∇L = (2, 3)。

| η | Δw | 步長 |
|---|---|---|
| 0 | (0, 0) | 0（不動，訓練死掉） |
| 0.01 | (−0.02, −0.03) | 0.036 |
| 0.1 | (−0.2, −0.3) | 0.36 |
| 1 | (−2, −3) | 3.6 |

單位的完整推導見 5b。

對照：換 checkpoint 時誰變。

| 物件 | 換點變嗎 | 為什麼 |
|---|---|---|
| L 這個函數（地形） | 不變 | 由架構、資料、量尺定 |
| L(w) 的值（高度） | 變 | 換位置換高度 |
| ∇L(w) | 變 | 坡度是地形在該點的性質 |
| Δw = −η∇L | 變 | 由 ∇L(w) 算出 |
| η | 不變 | 你設的，不看 w |
| 負號 | 不變 | 規則 |

**濃縮：Δw = −η∇L 是「讓 ΔL = ∇L·Δw 在等長步裡最負」的唯一解；負號選上下、η 選步長，缺一步必壞；新檔 = 舊檔 + Δw。**

## 5b. 單位分析：為什麼 η 的單位是 w²/L

**種子：每個量都有兩層——數值 ＋ 單位；單位裡的斜線記錄這個量怎麼造出來的，不做除法、沒有值。**

- ✅ 梯度是變化率，單位與 Δw 不同；負號與 η 的作用是把這個變化率轉成 Δw 的單位。
- ✅ ∇L 的值是一支向量，單位是「L 每 w」；η 的單位是 w²/L；兩者相乘 (w²/L)·(L/w) = w，剛好是 Δw 的單位。
- 🔄 負號不帶單位，只翻方向；單位全部由 η 承擔。
- 🔄 [η] 不是算出來的，是**倒推**的：等式兩邊單位要一致，∇L 帶 [L]/[w]，左邊要剩 [w]，所以 η 被迫是 [w]²/[L]。平方來自 w 的單位在等式裡出現兩次（左邊 Δw 一次、右邊 ∇L 分母一次）。
- 🔄 「每個 L 有多少 w 平方」是字面讀法，沒有意義；單位系統裡總有一個是配額，訓練裡大家讓 η 當配額。想要有意義的版本，改記成時間：Δw = −∇L·Δt，η = Δt 帶 [時間]，∇L 變成速度 [w]/[時間]，代價是 L 的單位變成 [w]²/[時間]——配額只是搬家。
- 🔄 「每 w 多少 L」這個意義屬於 ∇L 的**數值**（例如 2：w 動 1、L 動 2），不屬於單位 [L]/[w]；單位只說「這是個 L 類 ÷ w 類的量」。把數值層的讀法套到單位層，就會卡住。
- 🔄 向量／純量是數值層的事：速度 (2, 3) 公尺/秒是兩個數、一個單位；∇L = (2, 3) 兩個數、一個單位「L 每 w」。從單位推不出 w 是不是向量；w 是向量是因為它有 n 個數值。
- 🔄 LLM 裡 w 無因次、L（交叉熵，nats）當純數，所以 [η] 約成純數——lr = 0.001 看起來沒單位，是兩邊都被約掉，不是它天生沒有。RTP 例裡鈕帶單位（倍、%、次），η 就必須帶單位，且三個鈕嚴格說各需自己的 η——這是「尺度不一時梯度下降會壞」的根源，Adam 類算法等於替每個鈕配各自的 η。

對照：速度例，數值與單位是兩條平行的線。

| 量 | 數值 | 單位 |
|---|---|---|
| 速度 | 3 | 公尺/秒 |
| 時間 | 5 | 秒 |
| 位移 = 速度 × 時間 | 3 × 5 = 15 | 公尺/秒 × 秒 = 公尺 |

對照：搬到梯度，η 是「時間」的角色。

| 量 | 數值 | 單位 | 對應 |
|---|---|---|---|
| ∇L | (2, 3) | [L]/[w]（L 每 w） | 速度 |
| η | 0.1 | [w]²/[L] | 時間 |
| −1 | −1 | 無 | 翻方向 |
| Δw = −η∇L | (−0.2, −0.3) | [w]²/[L] × [L]/[w] = [w] ✓ | 位移 |

對照：倒推 [η]。

```
Δw   =  −η · ∇L
[w]  =  [η] · [L]/[w]
[η]  =  [w]² / [L]
```

對照：具體單位驗證（溫度地形：w 是位置、L 是溫度）。

| | 單位 |
|---|---|
| [w] | 公尺 |
| [L] | 度 |
| [∇L] | 度/公尺 |
| [η] | 公尺²/度 |
| [η]·[∇L] | 公尺²/度 × 度/公尺 = 公尺 = [Δw] ✓ |

對照：數值有幾個 vs 單位有幾個。

| | 數值有幾個 | 單位有幾個 |
|---|---|---|
| 速度 (2, 3) 公尺/秒 | 2 | 1 |
| w = (1, 2) | 2 | 1 |
| ∇L = (2, 3) | 2 | 1 |
| L = 7 | 1 | 1 |

右欄永遠 1。

對照：單位層 vs 物件層分開看。

| | 物件（它是什麼） | 單位（標籤） |
|---|---|---|
| w | n 個數的向量，會變 | [w]，n 格共用 |
| L | 一個數，隨 w 變（不是常量） | [L] |
| ∇L | n 個數的向量 | 每格都是 [L]/[w] |
| η | 一個數，你設的 | [w]²/[L] |

**濃縮：∇L 的單位是 L 每 w、η 的單位是 w²/L，相乘剩 w；負號無單位；η 的單位是倒推的配額，不要替它找意義；向量是數值層的事，單位永遠一個。**

## 6. 向上／向下與函數的意義

**種子：向上／向下只回答「我要這個函數的值變大還是變小」，由目標決定，與大小無關。**

- ✅ 梯度向上／向下的目的是讓函數高度上升或下降；具體意義取決於該函數值是什麼意義。
- ✅ 訓練模型 = 把 checkpoint w 調到 L 的低點，過程透過梯度下降移動。
- 🔄 L 要小 → −η∇L；對數概似（F 段）、強化學習報酬要大 → +η∇L。交叉熵 = −log 概似，**降交叉熵 = 升概似**，同一梯度差一個負號。
- 🔄 RTP(w) 兩個方向都可能：低於設計值向上、高於設計值向下；釘目標可改寫成最小化 (RTP − 目標)²，又變回向下——程式裡幾乎只見梯度下降，是因為大家把目標都改寫成損失。
- 🔄 函數換了梯度就換：RTP 剛好 95% 時偏差平方的梯度為零，但 ∇RTP 本身不為零。
- 🔄 反向傳播的「反向」= 算梯度時穿層的順序（輸出 → 輸入），與加減號無關；它只負責算出同一支 ∇L。本篇不展開。

對照：

| 函數 | 目標 | 用哪個號 |
|---|---|---|
| 損失 L | 小 | −η∇L |
| 對數概似 | 大 | +η∇L |
| 強化學習期望報酬 | 大 | +η∇L |
| RTP，目前 92%，設計 95% | 升 | +η∇RTP |
| RTP，目前 97%，設計 95% | 降 | −η∇RTP |
| (RTP − 95%)² | 小 | −η∇（又變回向下） |

對照：兩個「方向」是不同的事。

| 名詞 | 「方向」指什麼 | 階段 |
|---|---|---|
| 反向傳播 | 計算順序：輸出 → 輸入，一層層算斜率 | 算出 ∇L |
| 梯度下降／上升 | Δw 取 −∇L 還是 +∇L | 用 ∇L 走一步 |

**濃縮：± 選值的升降，意義由函數決定；把目標改寫成損失，就一律向下。**

## 7. 停止條件

**種子：停止看的是 L 的值不再出現新低，不是梯度為零、不是 L = 0、不是梯度不變。**

- ✅ 不存在斷崖：梯度的邊界就是可微分；斷崖 = 不可微 = 沒有梯度，不在梯度下降範圍內。
- ✅ patience 是規則定義出來的結果：連續 k 次沒有新低就停；k + 1 次可能變也可能不變；k 有限所以不可能無窮撞牆。
- 🔄 三個不同的「零」：L = 0（零誤差，通常到不了，地形有地板）；∇L = 0（平地，理論停止條件，實務幾乎不會恰好為零）；連續幾步 ΔL ≈ 0（高度不再變，**實務停止條件**）。
- 🔄 ∇L ≈ 0 → Δw ≈ 0 → ΔL ≈ 0 成立；反過來不成立。
- 🔄 實務看**驗證集** L：訓練 L 還在降、∇L ≠ 0，但驗證 L 回升 → 過擬合（見 7b）→ early stopping，停在 ∇L ≠ 0 的點。
- 🔄 patience 規則：每段量一次驗證 L；連續 k 次沒刷新歷史最低就停、退回最佳存檔。多跑的 k 步是確認成本；錯過後續下降是接受的風險；k 越大越不易錯過、越耗算力。
- 🔄 patience 撞的牆是「局部讀數無法判定全局」：真谷底與台階在腳下完全一樣，沒有局部測試能分辨，只能多走 k 步去賭。
- 🔄 地形有地板：資料矛盾 (1,2) 與 (1,4) 時任何 w 都答不對，最低 L = 1 > 0；把 L = 0 當停止條件永遠不停。嫁接 B 段「最小值是變異數」。
- 嫁接 F 段停止規則悖論：何時停止收樣本 ↔ 何時停止走步，同樣是資料到齊前的規則。
- 備註：「連續 k 次」（consecutive）≠ 數學「連續性」（continuity），中文同字。

對照：三個零。

| 哪個零 | 意思 | 是停止條件嗎 |
|---|---|---|
| L(w) = 0 | 零誤差 | 不是；地形多有地板 |
| ∇L(w) = 0 | 平地 | 理論上是；實務幾乎不會恰好為零 |
| 連續幾步 ΔL ≈ 0 | 高度不再變 | **實務停止條件** |

對照：patience，k = 3。

| 步 | 驗證 L | 歷史最低 | 沒進步連續次數 | 動作 |
|---|---|---|---|---|
| 1 | 5.0 | 5.0 | 0 | 存檔 |
| 2 | 4.2 | 4.2 | 0 | 存檔 |
| 3 | 3.9 | 3.9 | 0 | 存檔（最佳） |
| 4 | 3.9 | 3.9 | 1 | 繼續 |
| 5 | 3.9 | 3.9 | 2 | 繼續 |
| 6 | 3.9 | 3.9 | 3 | **停，退回第 3 份** |

不是「在第四次停」，是第四次之後多看 k 次確認沒進步，再退回第三份。每份都存著，退回免費。

對照：四種情境。

| 情境 | 訓練 L | 驗證 L | ∇L | 停？ |
|---|---|---|---|---|
| 到了平地 | 不降 | 不降 | ≈ 0 | 停 |
| 開始過擬合 | 還在降 | 回升 | ≠ 0 | 停（early stopping） |
| 正常訓練中 | 降 | 降 | ≠ 0 | 繼續 |
| L = 0 | 0 | ? | 0 | 幾乎不會發生 |

對照：patience 撞的牆。

| 地形狀況 | 腳下看到什麼 | 繼續走會怎樣 | patience 能分辨嗎 |
|---|---|---|---|
| 真谷底 | 坡 ≈ 0，L 不降 | 永遠不降 | 不能 |
| 台階（平地後還有下坡） | 坡 ≈ 0，L 不降 | 走過去會再降 | 不能 |
| 狹谷鋸齒 | 坡不小，L 忽上忽下 | 慢慢降 | 看 k 夠不夠大 |
| mini-batch 抖動 | L 小幅上下 | 趨勢在降 | 看 k |

前兩列在腳下**完全一樣**，這就是牆。k → ∞ 等於永不停；k = 1 一次沒進步就停，抖一下就誤殺。

**濃縮：看 L 不看梯度；真谷底與台階腳下長得一樣，所以用「連續 k 次沒新低」去賭，退回最佳存檔。**

## 7b. 過擬合（overfitting）

**種子：過擬合 = 模型學到的是這份訓練資料的偶然，而不是資料背後的機制。**

- ✅ 處理過擬合 = 退回驗證 L 最低的那份 checkpoint（可能退好幾份），不是梯度向上走回去；Δw 的負號從頭到尾沒變。
- 🔄 資料 = 機制 + 雜訊（嫁接 A 段「母體 vs 樣本」）：訓練資料是母體抽出的一份樣本，機制在母體裡，雜訊只在這份樣本裡。
- 🔄 L_train 是用這份樣本造的地形。壓低它，先學到機制（新資料也適用）；壓到夠低後，剩下能降的只有雜訊，而雜訊只屬於這份樣本，背下來對新資料無用甚至有害。
- 🔄 所以需要第二張地形 L_val：用沒參加訓練的資料造，與 L_train 共享機制、不共享雜訊。梯度下降走在 L_train 上，L_val 只當溫度計讀（嫁接 G 段「探索資料不能再拿來驗證」）。
- 🔄 徵兆：兩張地形分岔——L_train 續降、L_val 回升。分岔點 = early stopping 要停的地方。
- 🔄 模型做得到背雜訊是因為鈕夠多：n ≫ 資料筆數時，地形有足夠自由度讓每筆都剛好答對，包括錯的那幾筆。
- 🔄 反向極端是欠擬合（underfitting）：鈕太少，連機制都學不全。
- 🔄 「過擬合」是現象，「退回存檔」是處理；驗證 L 回升是**讀數**，梯度向上是**動作**，兩者無關。

對照：分岔。

| 階段 | L_train | L_val | 在學什麼 |
|---|---|---|---|
| 初期 | 降 | 降 | 機制（兩份資料都受益） |
| 分岔點 | 降 | 最低 | 機制學完、雜訊還沒開始 |
| 後期 | 繼續降 | 回升 | 這份樣本的雜訊 |
| 極端 | → 0 | 很差 | 整份訓練資料背下來 |

對照：一維例子。三筆資料 (1, 2.1), (2, 2.9), (3, 4.2)，背後機制 y ≈ x + 1 加雜訊（+0.1、−0.1、+0.2）。

| 模型 | 鈕數 | 訓練誤差 | 新資料 x = 4（真值約 5） |
|---|---|---|---|
| 直線 y = ax + b | 2 | 不為零（三點不共線） | ≈ 5.2 |
| 二次曲線 y = ax² + bx + c | 3 | **恰好零**（三點三鈕，必穿過） | 6.0 |

二次曲線訓練誤差更低，新資料卻錯得多（偏 1.0 對偏 0.2）——它把第三筆的 +0.2 雜訊當成「加速上彎」的機制。**訓練誤差低不代表學到東西。**

對照：讀數 vs 動作。

| | 是什麼 | 誰做的 |
|---|---|---|
| 驗證 L 回升 | 讀數：走在 L_train 上的路，從 L_val 看起來開始變差 | 地形給的 |
| 梯度向上 Δw = +η∇L | 動作：故意讓某函數值變大 | 你刻意做的；過擬合處理裡**沒有這一步** |
| 退回存檔 | 動作：丟掉分岔點之後的檔，用驗證 L 最低那份 | 你做的；不是往回走 |

極端案例：資料只有 1 筆，任何有鈕的模型訓練誤差都能為零，L_val 毫無保證——過擬合的極限是「樣本太小、鈕太多」。若真對 L_train 做梯度向上，訓練 L 與驗證 L 一起變差，不會回到分岔點。

類比：考古題。只做這一份做到滿分 = 背答案；用沒看過的考卷測，才知道是背的還是會的。失效點：考題是人出的可猜，雜訊是隨機的不可猜。

**濃縮：訓練資料 = 機制 + 雜訊；L 壓過頭就開始背雜訊，訓練 L 續降、驗證 L 回升；處理是停下退回驗證 L 最低的檔，不是往上走。**

## 8. 適用範圍：∇ 不只給 L

**種子：∇ 吃任何「多輸入、單一實數輸出、局部平滑」的函數；L 只是訓練裡那個函數的名字。**

- ✅ 任意函數都可用 ∇ 概念，條件是可微與輸出純量。
- 🔄 純量 = 一個實數，條件的本質是「輸出能排大小」；複數沒有大小順序，所以複數輸出拆成兩個實數。
- 🔄 輸出是 m 維向量時，梯度升級成 m×n 的 Jacobian 矩陣（K 段「線性規則的紀錄表」）；M(x; w) 輸出整個字彙表的機率，所以要先造 L 壓成純量才有梯度可降——**L 是為了讓 ∇ 有東西可用而造出來的純量函數。**
- 🔄 不是「函數找 L」，是「L 自己是一個函數」；RTP、溫度、E[(X−μ)²] 直接 ∇，不需要 L。
- 🔄 常數函數到處可微、梯度到處為零：合法但無資訊。
- 🔄 複變函數的「複導數」是另一個概念，未接。

對照：

| 函數 | 輸入維度 | 輸出維度 | 有梯度（純量版）嗎 |
|---|---|---|---|
| L(w) | n | 1 | 有 |
| RTP(w₁,w₂,w₃) | 3 | 1 | 有 |
| 房間溫度 T(x,y,z) | 3 | 1 | 有 |
| E[(X−μ)²] 看成 μ 的函數 | 1 | 1 | 有（B 段：∇ = 0 的解是均值） |
| M(x; w) 輸出字彙表機率 | n | 字彙數 | 否 → Jacobian；或造 L 壓成純量 |
| \|x\| 在 x = 0 | 1 | 1 | 無（尖角） |
| 階梯函數在跳躍點 | 1 | 1 | 無（斷崖） |

對照：輸出型態。

| 輸出型態 | 能比大小嗎 | 得到什麼 |
|---|---|---|
| 一個實數 | 能 | 梯度 |
| 一個複數 | 不能 | 拆成兩個實數 → 2×n Jacobian |
| 一支 m 維實向量 | 不能 | m×n Jacobian |

對照：訓練裡哪個函數吃 ∇。

| 情境 | 要取 ∇ 的函數 | 需要另造 L 嗎 |
|---|---|---|
| 訓練 LLM | L(w) | L 本身就是造出來的那個 |
| 調 RTP | RTP(w) | 不用，已是純量 |
| 房間找熱源 | T(x,y,z) | 不用 |
| 對 M(x; w) 本身 | — | M 輸出向量：造 L 壓成純量，或拿 Jacobian |

**濃縮：∇ 是對任何合格函數都能用的運算；輸出變向量就升級成 Jacobian，不平滑就沒有；L 被造出來是因為 M 不合格。**

## 陷阱清單（這條線實際撞到的）

| ❌ 錯在哪 | ✅ 正解 | 為什麼 |
|---|---|---|
| 梯度 = 展開式的第一項 | 第零項是 f(x)；梯度是**第一階項的係數** | 「牛頓項」非標準名詞；牛頓法用第二階（Hessian） |
| 梯度定義裡帶「釘住 n−1 個」 | 那是**一個偏微分**的做法；做 n 次才成梯度 | 釘住屬於分量，不屬於梯度的定義 |
| 梯度是一個面 / 是 n−1 維 | 梯度是切平面的**斜度**，n 個分量；n−1 維的是等高面，梯度是它的法向量 | 物件 vs 物件性質（面 vs 面的斜度） |
| 梯度的座標是觀測資料 | 座標是**權重**；資料固定、塑造地形 | L 吃 w，M 才吃資料 |
| 只有大廠 pre-training 才是「真訓練 M」 | pre-training 與 fine-tuning 同一機制，差在起點、資料、規模 | L 是唯一把手，誰都繞不過 |
| 一個點有 n 個梯度 | 一個點有 n 個偏微分、**一支**梯度 | n 是分量數不是梯度數 |
| 一個 checkpoint 一個 L | 一張地形無數個點；每點有一個 L **的值** | L 是地形、w 是位置 |
| 分量相減 / 相對其他分量的差 / 多變數之間的關聯（撞了三次） | 梯度記的是 n 條「**輸入 → 輸出**」的變化率；輸入之間無關聯被記錄 | 關係的另一端永遠是輸出 |
| 偏微分 = 釘住其他鈕時對應的高度 | 是高度的**變化率** | 高度是 L(w)，一個數，與梯度無關 |
| 差值 / 高度差 / 變化量 = 梯度分量（多次） | 分量是**率** = 高度差 ÷ 步長 | 量隨步長變、率不變，所以梯度是地形的性質 |
| 「高度差的變化率」 | 「高度**的**變化率」 | 多一個「差」字 = 多一階 → 曲率 |
| 「這一步」= ∇L / Δw 等價梯度 / Δw = ∇L | Δw = −η∇L：反向、乘係數 | ∇L 是率（讀數），Δw 是量（步）；單位不同只能成比例 |
| 負號 = 變化前的始量 / 終點 / wᵢ → w 的方向 | 負號 = 「每格預測的是升、我要降」的**選擇** | 梯度是率，沒有過去量、沒有終點；負號恆為 −1 不隨 w 變 |
| Δw 就是新 checkpoint | Δw 是差；新檔 = 舊檔 + Δw | Δ 永遠是前後差 |
| 單位是向量所以 w 是向量；L 是常量 | 向量／純量是**數值層**的事，單位永遠一個；L 是一個數但隨 w 變 | 「一個數」≠「常量」 |
| [η] = [w]²/[L] 是估值 / 用到均方 | [·] 念「……的單位」，是因次標籤 | 平方來自 w 的單位在等式裡出現兩次 |
| 測試點取 a₁ = a₂ = a₃ = a₄ | 各鈕取不同值 | 退化例看不出各分量為何不同（弱點模式 2） |
| L(w) = 0 是停止條件 / 停止條件是「梯度不再變」 | 看 L 的值連續 k 次沒新低 | L 有地板；梯度不變也可一路下降 |
| patience 撞的是連續性 / 斷崖 | 撞的是「局部讀數無法判定全局」 | 斷崖 = 不可微 = 根本沒梯度 |
| RTP 函數「不稱為梯度」 | ∇RTP 就是梯度 | 業內叫靈敏度，名字不同物件相同 |
| 驗證 L 回升時要「梯度向上校正」 | 停下、退回驗證 L 最低的那份檔 | 回升是讀數不是動作；Δw 的負號從未改變 |
| 過擬合是「回到上一個 checkpoint」 | 回到**驗證 L 最低**的那一個，可能退好幾份 | patience 多跑的 k 步都要丟 |

用詞備註（不計 ⚠️）：
- 「複函數」是聽錯：多變數（multivariable）≠ 複數函數（complex）。
- 「參數」是被動的鈕，「分量」是斜率放進向量後佔的格子；輸入端叫參數、輸出端叫分量。
- 「格子」是教學中的臨時用詞，作廢，只說「第 i 個分量」。
- 「相位」是複數的詞，這裡叫方向；方向與長度屬於整支向量，單一分量只是一個數。
- 「單位量」→「單位」；單位不是量。
- 「w 在 L 上的梯度」→「L 在 w 的梯度」，主詞是 L。

## 符號表

| 符號 | 念法 | 意思 |
|---|---|---|
| d/dx | dee | 一個變數的導數 |
| ∂ | partial / round d；中文「偏」 | 多變數版的 d，提醒其他鈕被釘住 |
| ∂L/∂wᵢ | partial L partial w i；「L 對 w_i 的偏微分」 | 只動第 i 個鈕，高度變化率；一個數 |
| wᵢ | w i | 第 i 個鈕，i = 1…n |
| ∇ | nabla（或 del）；中文直接念「梯度」 | 倒三角：對每個 wᵢ 各做一次 ∂，排成向量 |
| ∇L(w) | nabla L at w；「L 在 w 的梯度」 | n 個 ∂L/∂wᵢ 排成的箭，箭尾在 w |
| Δ | delta | 正三角：變化量、前後差，有限大小 |
| Δw | delta w | 你實際移動鈕的量；n 個數一支向量 |
| ΔL | delta L | 高度前後差；一個數 |
| ∇L·Δw | nabla L dot delta w | 內積：梯度與移動量配對 → 預測 ΔL |
| η | eta（艾塔） | 學習率，你設的正數，把率換成量 |
| ∝ | 正比於 | 比例，倍率留白 |
| [x] | x 的單位 | 因次標籤，不是取值 |

記法：∇ 倒三角尖端朝下像在探地形；Δ 正三角像山的高低差。

## 心智模型總結

```
checkpoint w ＝ 權重空間一個點（n 個鈕各一值）
地形 L(w)   ＝ 架構＋資料＋量尺 定出的一張固定地形，輸出一個實數
∂L/∂wᵢ      ＝ 釘住其他鈕、只動第 i 個，高度的變化率（高度差 ÷ 鈕的 Δ）
∇L(w)       ＝ n 個率排成一支向量；值是向量、單位是「L 每 w」
             讀法一：每鈕的靈敏度   讀法二：地板上指向最陡上坡的箭   ← 同一支（內積）
Δw          ＝ −η∇L：負號選下坡、η 把率換成量；w_new = w_old + Δw
單位        ＝ [∇L] = L/w，[η] = w²/L，(w²/L)·(L/w) = w ✓；負號無單位
保證        ＝ ΔL ≈ −η|∇L|² ≤ 0（步夠小）
±           ＝ 要值升還是降，由函數的意義決定
停          ＝ 驗證 L 連續 k 次沒新低 → 退回最佳存檔（不是 ∇L=0、不是 L=0）
過擬合      ＝ 壓過頭開始背這份樣本的雜訊；訓練 L 降、驗證 L 升 → 退檔，不往上走
一句話      ＝ 地形不動、人在動；讀坡、反走一小步、直到不再變低
```
