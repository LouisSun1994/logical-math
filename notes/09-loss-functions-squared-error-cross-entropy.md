## 0. 一句話版本

**損失函式不是溫度計，是「正確答案」的定義書：底的位置定義什麼叫對、漲法定義哪種錯重、底的高度是答案自己的雜訊；平方誤差是碗、交叉熵是牆，兩者都是 −log 概似，差在模型輸出的是一個數還是一個分佈。**

## 2. 損失函式的意義

**種子：損失函式 = 對「錯」的定義——不是回答「錯了沒」，而是「錯多少」，而且要讓每一種錯都能排大小。**

- ✅ 損失函式量的是預測與答案之間的落差；在訓練中它決定 w 怎麼移動，一路調到最佳點（= 驗證 L 最低的那份 checkpoint）。
- 🔄 要能排大小 → 輸出必須是一個實數（技術需求，08 筆記「適用範圍」段）。
- 🔄 答對時最低 → 損失的**最小點**就是你對「正確答案」的定義。你以為在量，其實在定義什麼叫對。
- 🔄 離最小點後怎麼漲 → 決定哪種錯比較嚴重。這是 ℓ 的設計空間：同資料換 ℓ，最低點搬家（08 筆記「點與地形」段的三列表）。
- 🔄 最小點通常到不了（資料有雜訊）→ 損失的**最小值**是答案本身的不可預測度，不是你的錯（08 筆記「停止條件」段「地形有地板」）。
- ⚠️ 「損失函式根本上只是一個測量的函式」：量落差對，但「只是測量」漏掉主結論——它的底定義了答案。
- ⚠️ 「損失函式的作用是估算 L 對於 w 的作用」：損失函式**就是** L，沒有第二個物件去估算它；而且方向反了，是 w 進、L 出。

對照：三個層次。

| 層次 | 問的問題 | 誰決定 |
|---|---|---|
| 最小點在哪 | 什麼叫「正確答案」 | 你選的 ℓ |
| 離最小點後怎麼漲 | 哪種錯比較嚴重 | 你選的 ℓ |
| 最小值是多少 | 答案本身的不可預測度（地板） | 資料，不是你 |

**濃縮：損失函式是「正確答案」的定義書，不是溫度計；最小點 = 答案、漲法 = 錯的輕重、最小值 = 答案自己的雜訊。**

## 3. ℓ 與 L：一把尺、N 張地形、合成一張

**種子：N 筆資料給 N 張地形，但只有一個 w；要讓一個 w 服務全部資料，必須先把 N 張地形合成一張。**

- ✅ 固定 w，每筆觀測進來得到一個高度 ℓᵢ（純量），N 個高度平均起來就是 L(w)；兩把尺都一樣。
- ✅ 每筆訓練資料代入**同一把尺** ℓ，各得一個自己的損失函式 ℓᵢ(w)；N 個相加除以 N 是總損失 L。
- ✅ 有幾張地形要合成，由資料筆數 N 決定；底落在哪，由餵什麼資料決定。
- 🔄 ℓ 吃 (預測, 答案)，預測 = M(xᵢ; w) 含 w；把第 i 筆的 xᵢ、yᵢ 填進去後，式子裡只剩 w，所以 ℓᵢ 是 w 的函數 = 一張地形。換一筆資料，填的數字不同，地形不同，尺沒換。
- 🔄 合成規則本身是選擇：相加（每筆投票）、取最大（只有最差那筆說話）、取最小（只有最好那筆說話）。訓練選相加；對交叉熵相加不是選擇是必然：Σ(−log pᵢ) = −log(Π pᵢ) = 整份資料的 −log 概似（02 筆記「貝氏 vs 頻率派」段）。
- 🔄 ÷N 不改任何事：地形等比例縮放，底不動。只讓不同 N 的 L 能放在一起比，順便讓 η 不用隨 N 重調。
- 🔄 L 有兩個方向可以切，互相垂直：按資料切出 ℓᵢ（索引 i），按參數切出 ∂L/∂wⱼ（索引 j）。
- 🔄 L 有兩個輸出被用到：坡度 ∇L(w) 決定 w 往哪移；高度 L(w) 給 checkpoint 打分，只在**比較**裡有意義（跟上一份比有沒有新低、訓練集 vs 驗證集比有沒有分岔）。patience、early stopping 看的全是高度。
- ⚠️ 「ℓ 是點的高度值，L 是整組函式」：ℓ 也是函式；「點的高度值」是 L(w)。函式 vs 函式的值。
- ⚠️ 「ℓ 是偏微分的某個損失函數」：偏微分是按參數切，ℓᵢ 是按資料切，兩件事。
- ⚠️ 「N 個維度就有 N 個小損失函數」：N 是資料筆數，n 是鈕數（維度），兩者無關；ℓᵢ 的數量跟 N 走，每張地形的維度跟 n 走。
- ⚠️ 「x₁…xₙ 參數輸入進去」：x 是資料，參數只有 w（08 筆記陷阱清單「梯度的座標是觀測資料」再犯一次）。
- ⚠️ 「求 L 是透過取均值、變異數的方式」：均值對，變異數不對——沒有任何一步算變異數；變異數是碗底的高度，是算出 L 之後看到的結果。

對照：四個物件。

| 物件 | 是什麼 | 吃什麼 → 吐什麼 |
|---|---|---|
| ℓ | 單筆的尺（函式） | (預測, 答案) → 一個數 |
| ℓᵢ(w) | 第 i 筆的地形（函式） | 已代入第 i 筆資料，只剩 w → 一個數 |
| L | 整張地形（函式） | w → 一個數 |
| L(w) | 點的高度（值） | 已代入 w |

對照：數量。

| 符號 | 有幾個 | 是什麼 |
|---|---|---|
| ℓ | 1 | 尺的規則（平方、或 −log p） |
| ℓᵢ(w) | N（資料筆數） | 尺套到第 i 筆資料上 |
| L(w) | 1 | N 張平均 |
| n | 鈕數 | 每張地形住在幾維；與 N 無關 |

對照：一把尺、三張地形。M(x; w) = w·x，資料 (1,2)、(2,3)、(3,5)，尺 = 平方（08 筆記「點與地形」段同一組資料）。N = 3、n = 1。

| | 代入後的式子 | w = 1 | w = 1.5 | w = 2 | 底在 |
|---|---|---|---|---|---|
| ℓ₁(w) | (2 − 1·w)² | 1 | 0.25 | 0 | 2 |
| ℓ₂(w) | (3 − 2w)² | 1 | 0 | 1 | 1.5 |
| ℓ₃(w) | (5 − 3w)² | 4 | 0.25 | 1 | 1.67 |
| L(w) = 平均 | | 2 | 0.17 | 0.67 | ≈ 1.64 |

三列是同一個「(答案 − 預測)²」填了不同數字；三個底各在不同處（三筆資料各自想要的 w），L 的底是妥協。

| 合成規則 | 誰說了算 | 底在哪 |
|---|---|---|
| 相加（= 平均） | 每筆都投票，拉力疊加 | 3（均值） |
| 取最大的 ℓᵢ | 只有最差那筆說話 | 3.5（1 和 6 的中點，2 被無視） |
| 取最小的 ℓᵢ | 只有最好那筆說話 | 1、2、6 三個底，沒用 |

對照：兩種切片。3 筆資料、2 個鈕，每格 = 第 i 筆對第 j 個鈕的拉力（數字是編的，只看結構）。

| | 對 w₁ 的拉力 | 對 w₂ 的拉力 |
|---|---|---|
| ℓ₁ | 2 | −1 |
| ℓ₂ | 4 | 1 |
| ℓ₃ | −3 | 3 |

一列 = 一筆資料對所有鈕的意見（ℓᵢ 的梯度）；一欄 = 所有資料對同一個鈕的意見，平均後是 ∂L/∂wⱼ；底列 = ∇L。第三筆想把 w₁ 往負拉，被前兩筆投票壓過。

對照：L 的兩個用途。

| 用的是 L 的什麼 | 用途 | 08 筆記在哪 |

| 坡度 ∇L(w) | 決定 w 往哪移 | 「一步」段 |

**濃縮：一把尺、N 筆資料、N 張地形、相加合成一張 L；橫向對資料平均、縱向對參數搜尋；按資料切是 ℓᵢ、按參數切是偏微分；L 用坡度決定怎麼走、用高度決定走得好不好。**

## 4. 平方誤差（squared error / MSE）：碗

**種子：錯多少 = 距離的平方。**

- ✅ 碗的特色：誤差大時罰得不成比例（錯 2 倍罰 4 倍）。
- 🔄 預測是數線上一點、答案也是數線上一點，兩點有距離，落差 = 距離。
- 🔄 對稱：多估 2 與少估 2 罰一樣。可以錯在兩邊。
- 🔄 在 0 附近平滑，處處有梯度（01 筆記「變異數與標準差」段「可微分」；08 筆記「適用範圍」段「|x| 在 0 沒有梯度」是反面）。
- 🔄 最小點是均值、最小值是變異數（01 筆記，形狀見第 7 節）。
- 🔄 代價：離群值一筆就能拉動整個底（02 筆記「尾巴分類」段：重尾資料配平方誤差，極端值主宰地形）。
- ⚠️ 「差值可能是高度」：差值是尺的**輸入**（橫軸），高度是尺的**輸出**（縱軸，損失值）。尺做的事就是把差值換成高度。

對照：同一組誤差，兩種尺怎麼罰。

| 誤差 | 平方 | 絕對值 | 平方 ÷ 絕對值 |
|---|---|---|---|
| 1 | 1 | 1 | 1 |
| 2 | 4 | 2 | 2 |
| 3 | 9 | 3 | 3 |
| 10 | 100 | 10 | 10 |

最後一欄一路漲：誤差越大，平方比絕對值「多在意」的倍數越大——離群值主宰的機制。

**濃縮：平方 = 碗：對稱、平滑、大錯罰平方倍；答案是均值、地板是變異數、弱點是離群值。**

## 5. 交叉熵（cross-entropy）：牆

**種子：錯多少 = 你給正確答案多少機率的「驚訝度」，驚訝度 = −log p(正確答案)。**

- 🔄 LLM 的輸出不是一個數，是字彙表上的機率分佈（把 1 單位信念分給各類別的分配表）；答案是「哪一個 token」，一個類別。
- 🔄 類別之間沒有距離（token 5 與 7 不比 5 與 500 近），沒有距離就沒有「距離的平方」。能量的只剩：分給正確答案的信念 p 有多少。
- 🔄 為什麼 −log 不是 1 − p：(1) 可加——整份資料的概似是一筆筆相乘，log 把乘變加，所以 Σ(−log p) = 整份資料的 −log 概似；降交叉熵 = 升概似是同一個數加負號，不是巧合（08 筆記「向上／向下」段那條的地基）。(2) 對自信的錯零容忍——p → 0 時 −log p → ∞；1 − p 最多罰到 1，p = 0.001 與 0.01 幾乎沒差。
- 🔄 交叉熵只看 p(正確答案)，**不管剩下的質量怎麼分**。這是「類別無距離」的直接後果，也是與平方誤差最大的性格差異。
- 🔄 單邊：p = 1 損失 0，p 只可能太小不可能太大。碗有兩個方向可以錯，牆只有一個。
- 🔄 地板：答案本身隨機（同一上文後面合法接好幾個 token）時，最好的預測是給出真實分佈 q，此時交叉熵降到 q 的熵 H(q)——答案自己的不確定度，再好的模型都壓不掉。與「平方誤差最小值是變異數」同結構。
- 🔄 高度的意義：改用 log₂，−log₂ p = 要幾個是非題才能猜到答案（p = 1/8 → 3 題、1/2 → 1 題、1 → 0 題）。交叉熵量的是「按你的信念分配，真相還需要多少資訊才說得出來」。類比失效點：p 不是 2 的冪次時題數非整數，當連續量。
- ⚠️ 「交叉熵作用在沒有高度的時候」：缺的不是高度是**距離**。交叉熵一樣吐出高度，只是沒有差值可當輸入，換了另一種輸入。
- ⚠️ 「牆的特色是 p < 1 顯著」：p < 1 只是「有錯」。牆的特色是 **p → 0 罰無限**、**單邊**。

對照：驚訝度表（nats，自然對數；換 log₂ 就是 bits，只差單位）。

| 給正確答案的 p | −ln p | 1 − p |
|---|---|---|
| 0.9 | 0.105 | 0.1 |
| 0.5 | 0.693 | 0.5 |
| 0.1 | 2.303 | 0.9 |
| 0.01 | 4.605 | 0.99 |
| 0.001 | 6.908 | 0.999 |

地板分解（記號）：

```
交叉熵(q, p) = H(q) + KL(q ‖ p)
               地板    你離真實分佈多遠
```

02 筆記「貝氏 vs 頻率派」段的 KL 量後驗離先驗多遠，這裡量模型離真相多遠；物件相同，兩端換人。

**濃縮：交叉熵 = −log p(正確答案) = 牆：單邊、log 讓概似可加、自信的錯爆炸、不管剩下的質量；答案是真實分佈、地板是熵。**

## 6. 統一：兩者都是 −log 概似

**種子：選量尺 = 選模型輸出的物件是一個數還是一個分佈；兩種選法取 −log 概似，就是兩把尺。**

- 🔄 01 筆記「常態密度公式」段：鐘形原型是 e^(−x²)。把預測當常態中心、誤差 (y − ŷ) 丟進去，取 −log，log 與 e 抵消，剩下 (y − ŷ)²。平方誤差 = 「預測一個數、假設雜訊是常態」的 −log 概似。
- 🔄 絕對值誤差對應另一種雜訊（Laplace，尖頂重尾）。交叉熵 = 「模型直接輸出分佈」的 −log 概似，中間不用再假設雜訊形狀。
- 🔄 所以 01 筆記「為什麼平方不用絕對值」的更深一層答案：**選平方 = 假設雜訊是常態**。常態假設崩（重尾）時平方誤差跟著崩——接 02 筆記「尾巴分類」段、03 筆記（重尾派彩）。

記號：

```
密度 ∝ e^( −(y−ŷ)² / 2σ² )
取 −log  →  (y−ŷ)² / 2σ²  ＋ 常數
```

對照：三把尺並排。

| 量尺 | 適用輸出 | 最小點（答案） | 最小值（地板） | 隱含假設 | 大錯怎麼漲 |
|---|---|---|---|---|---|
| 平方誤差 | 連續值 | 均值 | 變異數 | 常態雜訊 | 平方 |
| 絕對值誤差 | 連續值 | 中位數 | 平均絕對偏差 | Laplace 雜訊 | 線性 |
| 交叉熵 | 類別／分佈 | 真實分佈 q | 熵 H(q) | 輸出本身就是機率模型 | −log，p→0 無上限 |

對照：碗 vs 牆。

| | 平方誤差 | 交叉熵 |
|---|---|---|
| 預測是什麼物件 | 數線上一點 | 1 單位信念的分配表 |
| 答案是什麼物件 | 數線上一點 | 發生的那個類別 |
| 尺的輸入 | 兩點的差值 | 放在真相上的信念 p |
| 單筆曲線形狀 | 碗（對稱、兩邊可錯） | 牆（單邊、p→0 無限） |
| 多筆疊起來的底在哪 | 均值 | 頻率 |
| 底的高度 | 變異數 | 熵 |
| 高度的單位 | （答案單位）² | nats（驚訝度） |

```
平方誤差（碗）              交叉熵（牆）
 \        /                  |
  \      /                   |
   \    /                    \
    \__/                      \____
    答案                     0      p      1
```

類比：平方誤差是罰款按超速的平方算（超 10 罰 100、超 20 罰 400）；交叉熵是罰「你敢說不可能的事發生了」（說 1% 罰 4.6、0.1% 罰 6.9、0% 罰無限）。失效點：罰款可封頂，交叉熵不行，這正是它的設計。

**濃縮：平方誤差與交叉熵都是 −log 概似；差在模型輸出一個數（＋常態雜訊假設）還是一個分佈。**

## 7. 底在哪：拉力規則

**種子：ℓ 的形狀 = 每一筆樣本對 w 的拉力規則；碗底／牆底 = 所有拉力抵銷的地方。**

- 🔄 N 筆樣本每筆都想把預測拉向自己的答案。拉力 = ℓ 在那一點的坡度（記號：碗 e² 的坡度是 2e；牆 −ln p 的坡度是 1/p；當讀數不推）。梯度下降每一步 = 順著所有拉力的合力走。
- 🔄 碗的拉力 ∝ 距離：錯 10 的樣本拉力是錯 1 的 10 倍。訓練注意力自動集中在大誤差樣本——「離群值主宰」的具體機制。
- 🔄 合力為 0 ⇔ Σ(c − yᵢ) = 0 ⇔ c = 均值。**均值不在尺裡，是很多口碗疊起來的底**：平均了 ℓ、搜尋了 c 之後，底自己掉在那裡。01 筆記「均值是最小化點」= 均值是搜尋的答案，不是搜尋的方法。
- 🔄 牆的拉力 ∝ 1/p：p = 0.01 的樣本拉力是 p = 1 的 100 倍；p ≈ 1 的樣本幾乎不拉。訓練注意力自動集中在**自信答錯**的樣本，答對的自動退場。
- 🔄 少數派被壓得越扁拉得越兇，所以永遠押不死任何一邊，底只能落在頻率上。碗沒有這個性質（孤單的 6 拉力只線性長）。
- ⚠️ 「均值要靠帶入不同參數然後取均值」（後澄清為表達問題）：對參數是搜尋，不是平均；平均只對資料做。
- ⚠️ 「均值在於 L 梯度會趨近均值」：兩個不同的「均值」被黏在一起（見第 8 節的對照表）。

> **補強**（入庫時加，非這條線的導師內容）：「拉力 ∝ 1/p」是 ℓ 對 **p** 的坡度，p 本身就是鈕時（下表的 p_B）直接成立。LLM 的鈕在 softmax 之前（logit）；接到 logit 上時，1/p 被 softmax 自己的坡度 p(1 − p) 抵銷，對正確類別 logit 的拉力 = p − 1，絕對值最多 1：自信答錯（p → 0）拉力趨近 1、答對（p → 1）趨近 0。結論方向不變（答對的退場、自信答錯的被拉最兇），但「100 倍」是對 p 的讀數，不是對 w 的——p → 0 時爆炸的是**損失值**，不是梯度。

類比：每筆答案是一根彈簧綁著 c，彈簧力 ∝ 伸長量（虎克定律），平衡點 = 重心 = 均值。失效點：彈簧兩邊對稱，牆不是。

對照：碗的拉力抵銷。答案 1、2、6，每筆拉力 = c − yᵢ（正 = 往左拉、負 = 往右拉）。

| c | 答案 1 拉 | 答案 2 拉 | 答案 6 拉 | 合力 | 往哪走 |
|---|---|---|---|---|---|
| 2 | 1 | 0 | −4 | −3 | 往右（往 6） |
| 3 | 2 | 1 | −3 | **0** | 停：碗底 |
| 4 | 3 | 2 | −2 | 3 | 往左 |

對照：三口碗疊起來。答案 1、2、6，L(c) = 平均 (c − yᵢ)²。

| 預測 c | (c−1)² | (c−2)² | (c−6)² | L |
|---|---|---|---|---|
| 2 | 1 | 0 | 16 | 5.67 |
| 3 | 4 | 1 | 9 | **4.67** |
| 3.5 | 6.25 | 2.25 | 6.25 | 4.92 |
| 4 | 9 | 4 | 4 | 5.67 |

底在 3 = 均值；底的高度 4.67 = 變異數。

對照：一筆離群值拉動碗底。把 6 換成 9（答案 1、2、9）。

| 預測 c | (c−1)² | (c−2)² | (c−9)² | L |
|---|---|---|---|---|
| 3 | 4 | 1 | 36 | 13.67 |
| 4 | 9 | 4 | 25 | **12.67** |
| 5 | 16 | 9 | 16 | 13.67 |

底從 3 搬到 4（= 新均值），地板從 4.67 升到 12.67：一筆拉遠，底跟著走、地板跟著高。

對照：很多面牆疊起來。同一上文 10 次：7 次 B、3 次 C，預測 (p_B, p_C)，L = 0.7·(−ln p_B) + 0.3·(−ln p_C)。

| 預測 (p_B, p_C) | 0.7·(−ln p_B) | 0.3·(−ln p_C) | L |
|---|---|---|---|
| (0.5, 0.5) | 0.485 | 0.208 | 0.693 |
| (0.6, 0.4) | 0.358 | 0.275 | 0.633 |
| (0.7, 0.3) | 0.250 | 0.361 | **0.611** |
| (0.8, 0.2) | 0.156 | 0.483 | 0.639 |
| (0.9, 0.1) | 0.074 | 0.691 | 0.765 |
| (1.0, 0.0) | 0 | ∞ | ∞ |

底在 (0.7, 0.3) = 頻率；底的高度 0.611 = 這個分佈的熵。最後一列是牆的本性：押死一邊，另一邊發生過一次，損失無限。

對照：牆的拉力抵銷。每次 B 拉 p_B 往上，力 1/p_B；每次 C 拉 p_C 往上（= 拉 p_B 往下），力 1/p_C。

| (p_B, p_C) | 7 個 B 合拉 7/p_B | 3 個 C 合拉 3/p_C | 誰贏 | p_B 往哪 |
|---|---|---|---|---|
| (0.5, 0.5) | 14 | 6 | B | 升 |
| (0.7, 0.3) | 10 | **10** | 平 | 停：牆底 |

C 只有 3 筆，被壓到 0.1 時每筆拉力 10，三筆合力 30，壓過 7 筆 B。

**濃縮：ℓ 的形狀是拉力規則——碗拉力 ∝ 距離、牆拉力 ∝ 1/p；梯度是合力；底是合力為零處，碗底在均值、牆底在頻率；均值與變異數都是結果，不是方法。**

## 8. 旁支：平均運算與 LLN / CLT

**種子：固定 w，每筆觀測給一個高度，L(w) 是這些高度的樣本平均——所以它受 01 筆記「大數法則 vs 中央極限定理」段那個平均運算的全部結論管。**

- 🔄 w 要釘住。換 w 就換了一個隨機變數，表要重做（= 第 3 節「橫向平均、縱向搜尋」）。
- 🔄 01 的種子「平均運算是把變異數除以 n、把形狀推向常態的運算」拆成兩半：LLN（Law of Large Numbers，大數法則）管平均會落在**哪裡**（位置）；CLT（Central Limit Theorem，中央極限定理）管落點周圍**散多開、什麼形狀**（常態、寬度 σ/√N）。
- 🔄 L_N(w) → E[ℓ](w)：樣本地形高度趨近真地形高度，歸 LLN。有限 N 時 L_N 在真地形周圍抖，寬度 σ/√N，歸 CLT。
- 🔄 梯度也是平均：導數對加法可拆（記號性質），∇L_N(w) = N 支 ∇ℓᵢ(w) 的平均。batch 梯度趨近真梯度歸 LLN；抖動寬度 ∝ 1/√(batch size) 歸 CLT（batch 開 4 倍抖動縮一半）。08 筆記「點與地形」段「mini-batch 使每步看到的是地形的近似，略有抖動」：近似是 LLN 保證的，抖動是 CLT 量的。
- 🔄 底的**位置**隨 N 越來越穩（LLN）；底的**高度**（地板）不降，趨近母體自己的散佈。一份資料可以同時「底很穩」且「地板很高」。
- 🔄 N 大只解決穩不穩，不解決對不對：資料多但來源偏，底穩穩落在偏的地方。資料 = 機制 + 雜訊（08 筆記「過擬合」段）：N 大讓雜訊抵銷、機制留下；N 小時雜訊沒被抵銷，模型連雜訊一起學。
- 🔄 這條旁支**不是損失函式的意義**，是「用樣本算出來的 L 和 ∇L 是隨機物件」這件事的說明。
- ⚠️ 「CLT 是用在梯度會趨近某個均值」：趨近均值是 LLN；CLT 是抖多大。定理名對調。
- ⚠️ 「越多筆，均值要嘛集中要嘛離散」：越多筆只會集中（底的位置）；「離散」是地板的事，由資料本身的雜訊決定，與 N 無關。

> **補強**（入庫時加，非這條線的導師內容）：「抖動寬度 σ/√N」的前提是 ℓᵢ 的變異數有限（01 筆記「大數法則 vs 中央極限定理」段的 CLT 前提）。平方誤差把誤差再平方一次：ℓ = e² 的變異數要 e 的**四階**動差存在。重尾資料（02 筆記「尾巴分類」段：動差存不存在看尾巴）下這條件可能不成立——L_N 的抖動不按 1/√N 縮、形狀也不趨近常態；第 4 節「離群值主宰」從平均運算這一側看，就是同一件事。交叉熵那邊對應的條件是 p 不會真的碰到 0（−log p 才有界）。

對照：統計 ↔ 訓練（w 固定）。

| 統計 | 訓練（w 固定） |
|---|---|
| 母體 | 所有可能出現的資料 |
| 一次觀測 X | 一筆資料進來的高度 ℓᵢ |
| 母體均值 μ | 真地形在 w 的高度 E[ℓ](w) |
| 樣本均值 X̄ | L_N(w)——算得出來的那個 |
| 母體變異數 σ² | 各筆高度散得多開 |
| X̄ 的標準差 σ/√N | L_N(w) 的抖動 |

對照：LLN 與 CLT 分工。

| 問題 | 誰回答 | 套到這裡 |
|---|---|---|
| 平均會落在哪裡 | LLN | L_N(w) → E[ℓ](w)；batch 梯度 → 真梯度 |
| 落點周圍散多開、什麼形狀 | CLT | 抖動 ≈ 常態、寬度 σ/√N；batch 越大抖越小 |

對照：batch 大小的極端。

| batch 大小 N | L_N 與 ∇L_N | 誰在管 |
|---|---|---|
| 1 | 就是那一筆的 ℓ 和 ∇ℓ，沒有平均，抖到最大 | CLT：σ/√1 = σ |
| 整個訓練集 | batch 抖動消失，但「樣本 vs 母體」的差距還在（08 筆記「過擬合」段） | LLN 還沒到 ∞ |
| → ∞ | 真地形、真梯度 | LLN 的極限 |

對照：底的位置 vs 地板，隨 N。

| 物件 | 隨 N 增加 | 由什麼決定 |
|---|---|---|
| 底的位置（均值／頻率） | 越來越穩，趨近母體的底（LLN） | 資料從哪個母體來 |
| 底的高度（地板 = 變異數／熵） | 不降，趨近母體自己的散佈 | 資料本身有多雜 |

對照：資料筆數的極端。

| N | 底在哪 | 地板 | 意義 |
|---|---|---|---|
| 1 | 那一筆的答案 | 0 | 完美貼合一筆，毫無意義——08 筆記「過擬合」段的極限 |
| 少 | 被個別樣本拉動 | 偏低（雜訊被背掉一部分） | 過擬合風險區 |
| → ∞ | 母體的底 | 母體變異數／熵 | 真地形 |

對照：兩個「均值」。

| 哪個均值 | 是什麼 | 歸誰管 |
|---|---|---|
| 答案的均值（碗底位置） | 拉力抵銷的位置 | ℓ 的形狀（第 7 節） |
| 梯度的期望值 | batch 梯度 = N 筆拉力的平均，N 大時趨近母體平均拉力 | LLN |

```
母體 ──抽 N 筆──▶ 樣本 ──對每筆算 ℓ、取平均──▶ 樣本地形 L_N(c)
                                                   │ LLN：N→∞ 趨近真地形 E[ℓ]
                                                   │ CLT：有限 N 時在真地形周圍抖 ∝ 1/√N
                                             縱向搜尋 ──▶ 谷底 ĉ（= 均值／頻率，是結果）
```

**濃縮：L 是樣本平均，LLN 說它落在真地形上、CLT 說它抖多大；筆數多讓底的位置穩，不讓地板低；餵什麼資料決定底在哪——多只保證穩，不保證對。**

## 陷阱清單（這條線實際撞到的）

| ❌ 錯在哪 | ✅ 正解 | 為什麼 |
|---|---|---|
| 損失函式「只是」測量的函式 | 它量落差，但它的**底定義了什麼叫正確答案** | 最小點 = 答案、漲法 = 錯的輕重、最小值 = 地板 |
| 損失函式的作用是估算 L 對 w 的作用 | 損失函式**就是** L；w 進、L 出 | 沒有第二個物件；方向同 08 備註「L 在 w 的梯度」 |
| 差值可能是高度 | 差值是尺的**輸入**、高度是**輸出** | 尺做的事就是把差值換成高度 |
| 交叉熵作用在「沒有高度」時 | 缺的是**距離**不是高度 | 類別無距離，所以換輸入；高度（損失值）照樣有 |
| 牆的特色是 p < 1 顯著 | 特色是 p → 0 罰無限、單邊 | p < 1 只是「有錯」 |
| ℓ 是點的高度值 | ℓ 是函式；點的高度值是 L(w) | 函式 vs 函式的值（弱點模式 3：物件 vs 物件性質） |
| ℓ 是偏微分的某個損失函數 | ℓᵢ 是按**資料**切，∂L/∂wⱼ 是按**參數**切 | 索引 i 與 j 互相垂直 |
| N 個維度就有 N 個小損失函數 | N 是資料筆數、n 是鈕數，無關 | ℓᵢ 的數量跟 N，地形的維度跟 n |
| x₁…xₙ 是參數 | x 是資料，參數只有 w | 08 陷阱清單「梯度的座標是觀測資料」再犯 |
| 對參數帶入不同值然後取均值 | 對參數是**搜尋**（挑最低），對資料才是平均 | 橫向平均、縱向搜尋；把 L 的各值平均沒有意義 |
| 均值在於 L 梯度會趨近均值 | 碗底在均值（ℓ 形狀）與 batch 梯度趨近期望值（LLN）是兩個均值 | 共同點只有「平均」這個運算 |
| 求 L 透過取均值、變異數 | 只有平均；變異數是碗底高度，算完才看到 | 均值是底的位置、變異數是底的高度，都是結果不是方法 |
| CLT 用在梯度趨近某個均值 | 趨近是 LLN；CLT 是抖動的形狀與寬度 | 位置 vs 散佈 |
| 越多筆，均值要嘛集中要嘛離散 | 只會集中；離散是地板，由資料雜訊決定 | 底的位置與底的高度是兩個物件 |
| 一直重複時用 patience | 條件是驗證 L 連續 k 次**沒有新低**（持平、回升都算） | 08 筆記「停止條件」段 |

用詞備註（不計 ⚠️）：
- ℓ 不是 partition，是小寫 L（script ell），念 ell；斜體是為了跟 1、I 區分。
- 「L(w) 做多次取均值」→「ℓ 做 N 次（每筆一次）取均值，**得到** L(w)」：L(w) 是結果不是被平均的東西。
- 「估算」→ 量的是「預測」與答案的落差；它不估算任何東西。
- 「樞紐損失函式」→ 總損失／地形。
- 「這個 w 的 L」→ L 是整張地形，L(w) 才是在這個 w 的高度。
- 「每筆資料都有一個損失函式」：可接受，指的是地形 ℓᵢ(w)（N 張）；不能指尺的規則（只有 1 把）。
- 「規格定義」→ 規則（patience 的 k 是你設的）。
- 「最佳點」= 驗證 L 最低的那份 checkpoint，不是真地形谷底；停下時通常 ∇L ≠ 0。
- 「梯度向下」→ 梯度下降（gradient descent）。

## 心智模型總結

```
損失函式   ＝ 對「錯」的定義書：底的位置 = 答案、漲法 = 錯的輕重、底的高度 = 地板（資料自己的雜訊）
ℓ          ＝ 一把尺，(預測, 答案) → 一個數；代入第 i 筆 → ℓᵢ(w)，N 筆 N 張地形
L(w)       ＝ N 張相加 ÷ N：每筆投票的合成規則；橫向對資料平均、縱向對參數搜尋
切片       ＝ 按資料切出 ℓᵢ（i）、按參數切出 ∂L/∂wⱼ（j），互相垂直
用途       ＝ 坡度 ∇L 決定怎麼走；高度 L(w) 拿來比 checkpoint（停、分岔）
碗         ＝ 平方誤差：對稱、拉力 ∝ 距離 → 底在均值、地板 = 變異數、離群值主宰
牆         ＝ 交叉熵：單邊、拉力 ∝ 1/p → 底在頻率、地板 = 熵、自信的錯爆炸、不管剩下的質量
統一       ＝ 兩者都是 −log 概似；平方 = 輸出一個數 + 常態雜訊；交叉熵 = 輸出一個分佈
底         ＝ 合力為零處；均值／頻率是搜尋的結果，不是方法
旁支       ＝ L 是樣本平均：LLN 管底的位置、CLT 管抖動 1/√N；N 多底穩、地板不降；多只保證穩不保證對
一句話     ＝ 碗量距離、牆量驚訝；底是答案的定義，地板是答案的雜訊
```
