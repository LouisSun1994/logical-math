## 0. 一句話版本

**「證明」是系統內部的事，「真」是系統外部的事；對角論證就是讓一個東西指涉自己、逼出矛盾，Cantor、Turing、Gödel 用的是同一招。**

---

## 1. 概念樹骨架

```
自指（種子 I）
 └─ 對角論證：讓一個東西指涉自己 → 矛盾
     ├─ Cantor：實數不可數
     ├─ Turing：停機問題不可判定
     └─ Gödel：編碼 → 算術句子談論自己 → 不完備
         ├─ 第一不完備定理：有真但不可證的句子
         ├─ 第二不完備定理：系統證不了自己的一致性
         └─ 完備性（系統）vs 真（語意）

數系的運算結構（10-14 支線）
 └─ 超運算塔：加 → 乘 → 冪 → 迭代冪次，同一條遞迴規則生成
     ├─ 只靠兩個原語：後繼（+1）與重複 → 塔內不會有新東西
     └─ 加 + 乘 共存 → 可編碼自指 → 不完備的「牆」在這裡立起來
```

嫁接點：超運算塔那條支線接回 I 段的「編碼 → 自指」：不完備需要加法和乘法同時在場，塔的前兩層就是它們。

## 2. I. 數理邏輯

**種子：對角論證 = 讓一個東西指涉自己，逼出矛盾。**

- 🔄 Gödel 編碼→自指；一、二不完備定理；完備性（系統）vs 真（語意）。
- 🔄 Cantor / Turing / Gödel 的共同結構；ZFC；公理／定理／真；¬P。
- 🔄 連續 vs 離散：判準是「有沒有中間態」。
- ⚠️ 「不可證明」≠「沒有真值」。

### 對照表：三個對角論證的共同骨架

| | 要列舉的東西 | 自指的方式 | 逼出的結論 |
|---|---|---|---|
| Cantor | 所有實數 | 造一個每一位都和第 n 個數不同的數 | 列舉漏了它 → 不可數 |
| Turing | 所有程式 | 造一個「問自己會不會停、然後反著做」的程式 | 停機問題不可判定 |
| Gödel | 所有算術句子 | 編碼後造一句「這句話不可證」 | 真但不可證 → 不完備 |

### 對照表：三個常被混在一起的詞

| 詞 | 屬於哪一層 | 意思 |
|---|---|---|
| 公理 | 系統內 | 起點，不證自明地採用 |
| 定理 | 系統內 | 從公理依規則推出來的句子 |
| 真 | 系統外（語意） | 在某個解釋下成立 |
| 完備 | 系統的性質 | 每個真句子都證得出來 |
| 一致 | 系統的性質 | 證不出 P 與 ¬P 同時成立 |

### 連續 vs 離散的判準

```
有中間態 → 連續
無中間態 → 離散
```
（這條接到 05 筆記 J 段：數線上的負號是鏡射、無中間態；進了平面才有旋轉的中間角度。）

## 3. 支線：超運算塔（2026-10-14 對話，僅憑摘要）

整條支線尚未復述確認，以下全標 🔄。

- 🔄 加法 → 乘法 → 冪 → 迭代冪次（tetration），全部由「重複上一層運算」這一條遞迴規則生成。
- 🔄 整座塔只用兩個原語：**後繼（+1）**與**重複**。所以往上蓋再多層，結構上都不會出現新東西；真正的新運算邏輯要嘛換生成規則（如 Bennett 的交換超運算，用對數共軛），要嘛放棄「運算必須由更簡單的運算疊出來」這個前提（抽象代數：tropical semiring、函數合成、群運算）。
- 🔄 遞迴式 H_{n+1}(a, b) = H_n(a, H_{n+1}(a, b−1))：先用乘法與冪的具體例子重建，最後才看一般記號。
- 🔄 不完備的「牆」不是加法立起來的：只有加法的 Presburger 算術是完備且可判定的；**加法與乘法同時在場**才能編碼自指。
- 🔄 超運算塔是 Peano 算術的底，不是全部數學的底：ZFC 建在集合隸屬關係上，不建在數上。

### 手填表：牆在哪裡

| 系統 | 有加法 | 有乘法 | 能編碼自指 | 完備？ |
|---|---|---|---|---|
| Presburger 算術 | 是 | 否 | 否 | 是（且可判定） |
| Peano 算術 | 是 | 是 | 是 | 否 |

一句濃縮：**塔再高也只有「+1 和重複」兩塊積木；牆是在加法與乘法碰面的那一刻立起來的。**

## 陷阱清單

1. ❌ 「不可證明」所以「真假未知」 → ✅ Gödel 句是**已知為真**但在系統內不可證；「真假未知」要留給連續統假設這種真正開放的問題 → 為什麼：「證明」是系統內部的事，「真」是系統外部的事，兩者是不同層的概念。此條在 10-05 已標 ⚠️，10-14 對話再次出現。
2. ❌（10-14，🔄 待確認）「數學建在加法上，所以一定有不可判定的句子」 → ✅ 三處要分開：(1) 超運算塔只是 Peano 算術的底，不是全數學的底；(2) 牆需要加法與乘法共存，不是加法單獨造成；(3) 見第 1 條 → 為什麼：把「一個系統的性質」推廣到「所有系統」，是物件 vs 類別層級的 type error。

備註（用詞）：「不完備」口語上常被聽成「有缺陷」；它只是「有真句子證不出來」這個精確性質。

## 心智模型總結

```
自指      ← 對角論證：Cantor / Turing / Gödel 同一招
不完備    ← 真（系統外）≠ 可證（系統內）；Gödel 句是真的
牆        ← 加法 + 乘法共存 → 能編碼 → 自指；只有加法則完備
塔        ← 後繼 + 重複；塔內無新邏輯，新邏輯要換生成規則或換前提
連續／離散 ← 有沒有中間態
```
