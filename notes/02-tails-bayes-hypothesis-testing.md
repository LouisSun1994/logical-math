## 0. 一句話版本

**尾巴輕重看危險率的升降；頻率派把隨機性掛在資料、貝氏把隨機性掛在信念；p 值是在 H₀ 底下看到至少這麼極端結果的機率，而實戰的坑多半出在「拿錯 null distribution」。**

---

## 1. 概念樹骨架

```
分佈的尾巴（種子 E）
 └─ 危險率 h(x) 升／平／降 → 輕尾／指數／重尾
     └─ 重尾 → 動差可能不存在 → 接回 01 筆記 C 段的前提失效

隨機性掛在哪（種子 F）
 ├─ 資料 → 頻率派 → 信賴區間（程序保證）→ 假設檢定（種子 G）
 └─ 信念 → 貝氏 → 後驗、共軛、KL、可信區間（命題機率）
```

嫁接點：E 接在 01 筆記 C 段「決定動差存在的是尾巴衰減速度」上；G 是 F 的頻率派分支往下長出來的；G 末條（重尾派彩）接到 03 筆記的 RTP。

## 2. E. 尾巴分類

**種子：危險率 h(x) = −d/dx log S(x) 的升降決定尾巴輕重。**

- ✅ 上升=輕尾、常數=指數、下降=重尾；指數分佈是中性分界。
- ✅ light / heavy / long / fat tail 定義與包含關係。
- ⚠️ 正確是 long-tail ⊂ heavy-tail。

### 對照表：危險率怎麼走，尾巴就怎麼分

| h(x) 隨 x 的走向 | 尾巴類別 | 直覺 | 代表 |
|---|---|---|---|
| 上升 | 輕尾（light） | 活越久越容易「結束」，極端值被壓住 | 常態 |
| 常數 | 指數（中性分界） | 無記憶，過去不影響未來 | 指數分佈 |
| 下降 | 重尾（heavy） | 活越久反而越難結束，極端值常見 | Pareto |

### 包含關係

```
fat tail ⊂ long tail ⊂ heavy tail
                       └─ 不是：heavy ⊂ long
```

一句濃縮：**尾巴不是看「值有多大」，是看「越往外走，結束的傾向是升是降」。**

## 3. F. 貝氏 vs 頻率派

**種子：隨機性掛在資料（頻率）還是掛在信念（貝氏）。**

- ✅ 貝氏定理四角色；後驗可累積、先驗被沖淡。
- ✅ Beta-Binomial 共軛；MCMC 用抽樣繞過正規化。
- ✅ 兩派都認為 p 固定；貝氏分佈畫的是「對 p 的知識」。
- ✅ 概似原則與停止規則悖論。
- ✅ 貝氏不需樣本；證據比樣本廣；後驗寬度是無知的尺寸。
- ✅ 資訊增益 = KL(後驗‖先驗)；單次觀測不保證減熵。
- ✅ 信賴區間（程序保證）vs 可信區間（命題機率）。

### 對照表：兩派差在哪、同在哪

| | 頻率派 | 貝氏 |
|---|---|---|
| 隨機性掛在 | 資料（重複抽樣） | 信念（對 p 的知識） |
| p 是什麼 | 固定未知常數 | 固定未知常數（相同！） |
| 畫出來的分佈是 | 估計量在重複抽樣下的分佈 | 「我對 p 知道多少」 |
| 區間 | 信賴區間：程序在長期中有 95% 蓋到 p | 可信區間：p 在裡面的機率是 95% |
| 需要樣本嗎 | 要 | 不一定；證據比樣本廣 |
| 停止規則 | 影響結論 | 不影響（概似原則） |

### 貝氏定理四角色

```
後驗 ∝ 概似 × 先驗        （分母：正規化常數，MCMC 用抽樣繞過它）
```

| 角色 | 是什麼 | 隨資料累積 |
|---|---|---|
| 先驗 | 看資料前對 p 的知識 | 被沖淡 |
| 概似 | 這組資料在各個 p 下出現的可能性 | 一次次相乘 |
| 後驗 | 看完資料後對 p 的知識 | 可累積，上一輪的後驗是下一輪的先驗 |
| 正規化 | 讓後驗面積 = 1 | 常常算不出來 → MCMC |

### 後驗寬度與資訊

```
後驗寬度 = 無知的尺寸
資訊增益 = KL(後驗 ‖ 先驗)
單次觀測不保證減熵：一筆意外的資料可能讓後驗變寬
```

一句濃縮：**兩派都說 p 是固定的；差別只在你把「不確定」這個東西放在資料上還是放在自己腦袋裡。**

## 4. G. 假設檢定

**種子：p 值 = 在 H₀ 下看到至少這麼極端結果的機率。**

- ✅ H₀/H₁、null distribution、Type I/II、「不拒絕」≠「接受」。
- ✅ null distribution 來源：理論或模擬（置換、蒙地卡羅）。
- ✅ 實戰坑：倖存者偏差；N 人必有最大值 → 要的是最大值的 null distribution；探索資料不能再驗證；要測異質性非母體均值。
- ✅ 浮動倍率派彩是重尾，RTP 收斂速度取決於倍率上限與觸發率。

### 對照表：兩種錯誤

| | H₀ 其實為真 | H₀ 其實為假 |
|---|---|---|
| 拒絕 H₀ | Type I（誤殺） | 正確 |
| 不拒絕 H₀ | 正確 | Type II（漏抓） |

「不拒絕」只是「證據不夠」，不是「接受 H₀ 為真」。

### 手填表：實戰坑的共同結構

每一個坑都是「拿了錯的 null distribution」或「資料已經被挑過」。

| 坑 | 錯在哪 | 應該拿什麼 |
|---|---|---|
| 倖存者偏差 | 只看活下來的 | 包含消失者的母體 |
| 「N 人中有人很極端」 | 拿單人的 null distribution | 拿 N 人最大值的 null distribution |
| 探索完再驗證 | 同一份資料先挑再測 | 新資料，或事先宣告的假設 |
| 問「母體均值是多少」 | 問錯問題 | 要測的是異質性（彼此是否不同） |

### 嫁接到應用：浮動倍率派彩

```
倍率浮動 → 派彩分佈是重尾（接回 E 段）
重尾 → 平均收斂慢（接回 01 筆記 C 段）
收斂速度由兩件事決定：倍率上限（尾巴被截在哪）、觸發率（多久抽到一次大的）
```

一句濃縮：**檢定的本體是 null distribution；大多數實戰錯誤是拿錯了它，不是算錯了 p。**

---

## 陷阱清單

1. ❌ heavy-tail ⊂ long-tail → ✅ long-tail ⊂ heavy-tail（fat ⊂ long ⊂ heavy） → 為什麼：long tail 是 heavy tail 再加一個條件（超過任一門檻後，再往外一段的條件機率趨近 1），條件越多集合越小。這是「尾巴相關的類別混淆」弱點模式的一例。

備註（用詞，非混淆）：「不拒絕 H₀」在口語上常被說成「接受 H₀」，守住的線是「證據不足」與「證明為真」不同。

---

## 心智模型總結

```
尾巴    ← 看 h(x) 升／平／降；fat ⊂ long ⊂ heavy
兩派    ← p 都固定；不確定掛資料 = 頻率派，掛信念 = 貝氏
貝氏    ← 後驗 ∝ 概似 × 先驗；寬度 = 無知；KL = 增益
檢定    ← p 值在 H₀ 下算；坑 = 拿錯 null distribution 或資料被挑過
派彩    ← 浮動倍率 → 重尾 → 收斂速度看上限與觸發率
```
