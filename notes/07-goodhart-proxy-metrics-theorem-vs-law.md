# Goodhart 定律：指標、目標、與「定律 vs 定理」

- 記錄日期：2026-10-20
- 來源：對話「介紹一下古德哈特定律」→ 四輪校正
- 目前定位：旁支。接在「觀測值 vs 均值」「物件 vs 物件性質」那條線上；同時正面撞到弱點 3（層級 type error）與弱點 4（不可證明 ≠ 沒有真值）

## 0. 一句話版本

指標是目標的估計量；拿估計量當目標去優化，等於專挑估計誤差最大的樣本。

## 1. 概念樹骨架

```
觀測值 vs 母數（既有）
└─ 指標(measure/proxy) 是 目標(goal) 的估計量
   ├─ 估計量有用的前提：在「無壓力分佈」下與目標相關
   ├─ 優化 = 搜尋極端 = 把樣本推到分佈尾巴（接 尾巴類別那條線）
   │  └─ 尾巴是相關性沒被驗證過的區域 → 相關崩壞
   ├─ 四種崩壞機制：regressional / extremal / causal / adversarial
   └─ Goodhart = selection bias 的特例，不是獨立新定律

物件 vs 物件性質（既有，弱點 3）
└─ 「命題在新區域不成立」≠「命題為假」：隱藏前件被拿掉，不是真理被推翻

不可證明 ≠ 沒有真值（弱點 4）
└─ 定理 / 定律 / 說法 三格，真值來源不同；「不是定理」只否定第一格，不掉到第三格
```

嫁接點：接在筆記裡「誤差 = 觀測值 − 均值」種子的下一層；尾巴部分接在「尾巴類別混淆」複習段。

## 2. 種子與演繹

**種子**：指標一旦變成目標，就不再是好指標。（Goodhart 1975；通行版為 Strathern 改寫）

- 🔄 指標與目標是兩個不同物件。目標量不到，所以量一個相關的東西。
- 🔄 相關是在「無人施力」的自然分佈上量的；優化改變了取樣分佈，相關性不保證跟著搬過去。
- 🔄 優化不是讓結果變隨機，是**系統性偏向**「指標升、目標不升」——因為那條路徑通常比較便宜（刷登入比做好玩簡單）。
- ✅ 「把指標當目標去追」是觸發 Goodhart 的動作；定律講的是後果（指標失效），不是動作本身。
- ✅ 追指標本身不錯，那是唯一能施力的地方；錯的是相信指標在壓力下仍可靠。
- ✅ A→B 是一種「現象」：有隱藏條件（無壓力）的經驗規律，不是無條件真理。
- ✅ Goodhart 說明的是「A→B 的可靠性依賴無壓力」。

```
機制            指標升而目標不升的原因                     遊戲例
regressional   指標 = 目標 + 雜訊，選最高指標 = 選最大雜訊   挑實測 RTP 最高的機台當最公平，挑到波動最大的
extremal       極端區相關性從未被驗證                     拉 ARPU 拉到只剩鯨魚，體驗結構整個換掉
causal         指標與目標只是共同結果，動指標不動因         強迫登入衝 DAU，DAU 升、好玩沒升
adversarial    對手主動找縫                              刷任務點數、代打、多開
```

濃縮：相關是在無壓力分佈上量的，優化改變了分佈。

## 3. 層級：Goodhart 推翻了什麼？

**種子**：Goodhart 不否定任何命題，它改變的是一個沒寫出來的前件的真值。

- ✅ 「用 B 倒出 A」= 把指標 B 當目標推，期望目標 A 跟上。
- 🔄 「用 B 倒出 A」同時踩兩個層級：邏輯層（A→B 不蘊含 B→A，跟壓力無關）與統計層（B 與 A 相關可賭，無壓力成立、有壓力崩）。Goodhart 殺的是第二層。
- 🔄 真理不會被推翻；會「不成立」的東西從一開始就不是真理，是有隱藏前件的條件句。

```
命題                                 是不是真理
P1 若指標高 則目標高                   從來不是：條件藏在句子外
P2 若無壓力 且 指標高 則目標高          是：Goodhart 發生後一字未變，只是前件被拿掉
P3 若把指標當目標 則指標失效            這就是 Goodhart，是成真的那條，不是被推翻的那條
```

可手填：

```
命題              隱藏前件       優化後前件還在?   命題本身是否仍真
指標高→目標高     ______        ______           ______
Goodhart          ______        ______           ______
```

濃縮：Goodhart 不推翻真理，它把你沒寫出來的前件從真變假。

## 4. 定理 vs 定律 vs 說法

**種子**：真值有三種來源——證明、證據、沒有。

- 🔄 定理（theorem）：從公理證出，系統內不能錯。定律（law）：從觀測驗證，可被推翻、目前未被推翻。說法（opinion）：無檢驗程序。
- 🔄 「能被推翻」正是有意義的證明；不可能錯的說法才是空話。
- 🔄 Goodhart 的可推翻條件：找到一個代理指標，大力優化後相關不減反增。
- 🔄 Goodhart 經驗上是定律，限定形式模型內（Manheim & Garrabrant 2018）可證成定理；多數物理定律同構。

```
類別     真值來源     能不能錯          例子
定理     證明        系統內不能        大數法則、畢氏定理
定律     證據        能，目前沒被推翻   牛頓第二定律、Goodhart
說法     無          無法判定          「這遊戲很有質感」
```

可手填：

```
命題                               類別    怎樣會被推翻                 目前狀態
Goodhart                          ___    ________________            ___
大數法則                           ___    ________________            ___
RTP 95% 的機台比 90% 的「好玩」      ___    ________________            ___
```

濃縮：定理靠證明為真，定律靠證據為真，說法沒有為真的程序。不是定理 ≠ 沒有真值。

## 5. 類比與失效處

- 體溫計：發燒→體溫高，拿體溫當健康指標；把「降體溫」當目標，冰敷就達標。
- 失效處：體溫計的失效路徑是靜態的；adversarial 機制是動態的，對手會持續找新縫。體溫不會反擊。

## 6. 應用對接

- RTP 是「公平感」的代理指標。把 RTP 數字當 KPI 死守，可做出 RTP 達標、變異數極端的機台——指標合格、目標不合格。

可手填（挑現場三個「指標合格但直覺不對勁」的非退化案例）：

```
______    ______     ___           ______________    ______
```

## 陷阱清單

- ⚠️ ❌ Goodhart = 倒果為因 → ✅ 倒果為因只是 causal 那一條；另外三條機制不是因果方向錯 → 因為 regressional 選雜訊、extremal 出驗證區、adversarial 是對手鑽縫，都沒有把效果當原因。
- ⚠️ ❌ 「若A則B 是真理，Goodhart 發生時它就不成立」 → ✅ A→B 有隱藏前件（無壓力）；Goodhart 拿掉前件，命題出定義域，不是變假 → 「不適用」與「為假」是兩個層級（弱點 3）。
- ⚠️ ❌ 施壓後「可能倒出 A、可能倒不出」五五開 → ✅ 系統性偏向倒不出 → 優化搜尋最便宜路徑，「指標升目標不升」通常更便宜。
- ⚠️ ❌ 「定律不是定理，所以沒意義、只是一種說法」 → ✅ 定律有真值，來源是證據；能被推翻正是有意義的證明 → 弱點 4 的原型；反問：F=ma 不是定理，有沒有意義？

備註（用詞，不列 ⚠️）：
- 「謬誤」：Goodhart 是統計現象 / 失效模式，不是推理形式錯誤。硬要找謬誤，是「相關→因果且假設相關在新分佈不變」。
- 「因為這定律變成有壓力」：因果順序反。推指標的動作製造壓力；定律描述後果。
- 「定律發生」：定律不發生，它描述；發生的是分佈改變。
- 「倒因為果」：慣用語為「倒果為因」，「導」為別字。
- 「可以說定理？」：不行，見第 4 段。

## 心智模型總結

```
目標量不到 → 量指標（估計量）
指標可靠的條件 = 無壓力分佈下與目標相關（前件藏在句子外）
推指標 = 製造壓力 = 把樣本推到尾巴 = 相關未驗證區 → 系統性偏向「指標升目標不升」
Goodhart 沒推翻任何命題，它把隱藏前件從真變假
Goodhart 是定律不是定理：真值來自證據，能被推翻，所以有意義
```
