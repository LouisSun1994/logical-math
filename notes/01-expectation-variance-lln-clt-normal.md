# 從期望值到常態：機率基礎、變異數、LLN vs CLT、常態密度

---

## 0. 一句話版本

**期望值是機率加權平均；變異數是誤差平方的期望值；「取平均」這個運算會把變異數除以 n、把形狀推向常態；常態密度只是 e^(−x²) 加上平移、拉寬、歸一三個零件。**

---

## 1. 概念樹骨架

```
期望值 E[X]（種子 A）
 └─ 誤差 = X − μ
     └─ 變異數 Var = E[(X−μ)²]（種子 B）
         ├─ 標準差 σ = √Var（回到原單位）
         ├─ 全期望 / 全變異數 → 混合分佈的 overdispersion
         └─ 平均運算 X̄ₙ（種子 C）
             ├─ LLN：位置 → μ
             ├─ 代數：Var(X̄ₙ) = σ²/n（任何 n 精確）
             └─ CLT：標準化誤差的形狀 → N(0,1)
                 └─ 常態密度（種子 D）：e^(−x²) + 三個零件
```

嫁接點：B 接在 A 的「誤差」上；C 接在 B 的 σ 上（σ/√n）；D 接在 C 的「形狀趨近常態」上。

---

## 2. A. 機率基礎

**種子：期望值 = 機率加權平均。**

- ✅ 離散用 Σ、連續用 ∫，同一個式子。
- ✅ 離散 vs 連續的判斷：單一值的機率是否 > 0；密度不是機率，機率是面積。
- ✅ 母體參數兩種來源：機制已知→按定義算出；機制未知→用樣本估計。數據是驗證或估計，不是「生出」μ。
- ✅ 合法分佈可以沒有均值（聖彼得堡：機率收斂 ≠ x·p(x) 收斂）。

### 對照表：離散 vs 連續

| | 離散 | 連續 |
|---|---|---|
| 單一值的機率 | > 0 | = 0 |
| 「機率」長什麼樣 | 一根根高度 | 曲線下的面積 |
| 密度 / 質量 | 質量函數 p(x) 就是機率 | 密度 f(x) 不是機率，可以 > 1 |
| 期望值記號 | Σ x·p(x) | ∫ x·f(x) dx |

### 手填表：母體參數從哪裡來

| 情境 | 機制已知？ | μ 怎麼來 | 數據的角色 |
|---|---|---|---|
| 公平骰子 | 是 | 按定義算：3.5 | 驗證 |
| 某台機台實際 RTP | 否 | 用樣本估計 | 估計 |
| 聖彼得堡遊戲 | 是 | 不存在（Σ 發散） | 任何樣本平均都不會穩定 |

一句濃縮：**數據不會「生出」μ；μ 要嘛由機制定義，要嘛被數據估計。**

## 3. B. 變異數與標準差

**種子：變異數 = 誤差平方的期望值。**

- ✅ RMS 三步：平方→平均→開根號；做到第二步是變異數，做完是標準差。
- ✅ 用平方不用絕對值：獨立時可加、可微分、均值是最小化點。
- ✅ σ² 原單位平方（用來算），σ 原單位（用來看）。
- ✅ 變異數 = 繞重心的轉動慣量 = 兩次獨立抽樣差值平方期望的一半。
- ✅ 全期望、全變異數公式；混合分佈多出 Var(E[X|p]) → overdispersion。
- ⚠️ 變異數是母體性質；樣本變異數（n−1）只是估計。

### 對照表：RMS 三步停在哪裡

| 步驟 | 動作 | 得到的東西 | 單位 | 用途 |
|---|---|---|---|---|
| 1 | 誤差平方 | (X−μ)² | 原單位² | 中間量 |
| 2 | 取期望 | σ²（變異數） | 原單位² | 用來算（可加） |
| 3 | 開根號 | σ（標準差） | 原單位 | 用來看 |

### 為什麼是平方不是絕對值（三個理由）

| 理由 | 內容 |
|---|---|
| 可加 | 獨立變數相加時，變異數直接相加；絕對偏差沒有這個性質 |
| 可微分 | 平方在 0 處平滑，絕對值在 0 處有尖角 |
| 均值是最小化點 | 讓 E[(X−c)²] 最小的 c 正好是 μ；絕對值版本最小化點是中位數 |

### 全變異數：混合分佈多出來的那一項

```
Var(X) = E[ Var(X|p) ] + Var( E[X|p] )
         ──────────────   ──────────────
         各成分內部的變異   成分之間均值的變異 → overdispersion
```

一句濃縮：**σ² 用來算、σ 用來看；混一起的分佈會多一塊「均值在飄」的變異。**

## 4. C. 大數法則 vs 中央極限定理

**種子：平均運算是把變異數除以 n、把形狀推向常態的運算。**

- ✅ LLN：位置收斂到 μ。CLT：標準化誤差的形狀趨近 N(0,1)。
- ✅ σ/√n 是純代數、任何 n 精確；「形狀是常態」才是 CLT 的近似。
- ✅ n 是極限變數；m 只是畫清直方圖。
- ✅ 常態是「取平均」的唯一不動點（變異數有限時）。
- ✅ 前提：獨立、同分佈、變異數有限。不滿足：Pareto(1<α<2) 收斂但非常態；Cauchy 不收斂不發散；Pareto(α≤1) 發散 → stable distributions。
- ✅ 批次「最大值」收斂到 Gumbel → 平均運算才是關鍵。
- ✅ N(μ,σ²)、z-score、68-95-99.7；柴比雪夫對任何有限變異數分佈成立。
- ⚠️ 「有界」≠「變異數有限」：有界 ⟹ 有限，反之不然；決定動差存在的是尾巴衰減速度。
- ⚠️ 「一個算出來的平均數」沒有分佈；有分佈的是抽樣前的隨機變數。
- ⚠️ Cauchy 不是「均值難找」，是「均值不存在」。

### 對照表：LLN 與 CLT 各管什麼

| | LLN | σ/√n | CLT |
|---|---|---|---|
| 說的是 | 位置 | 寬度 | 形狀 |
| 結論 | X̄ₙ → μ | Var(X̄ₙ) = σ²/n | 標準化誤差 → N(0,1) |
| 精確還是近似 | 極限 | 任何 n 都精確（純代數） | 近似，n 越大越好 |
| 需要什麼 | 均值存在 | 變異數存在 | 獨立、同分佈、變異數有限 |

### 手填表：前提不滿足時的三種結局

| 母體 | 均值存在？ | 變異數有限？ | 平均的位置 | 平均的形狀 |
|---|---|---|---|---|
| 有限變異數（一般情形） | 是 | 是 | 收斂到 μ | 常態 |
| Pareto，1 < α < 2 | 是 | 否 | 收斂 | 非常態（stable） |
| Cauchy | 否 | 否 | 不收斂也不發散 | 永遠是 Cauchy |
| Pareto，α ≤ 1 | 否 | 否 | 發散 | — |

### n 與 m 的分工

```
n：每一次平均用了幾個樣本 → 決定 σ/√n 與 CLT 的逼近程度（極限變數）
m：重複做了幾次平均      → 只是讓直方圖畫得更清楚，不改變分佈本身
```

### 「平均」才是關鍵運算

```
批次取平均  → 常態（Gaussian）
批次取最大值 → Gumbel
```
同樣的母體、同樣的 n，換掉運算就換掉極限分佈。常態是「取平均」這個運算的唯一不動點（變異數有限時）。

一句濃縮：**LLN 管位置、CLT 管形狀、σ/√n 管寬度且不需要任何極限。**

## 5. D. 常態密度公式

**種子：鐘形的原型是 e^(−x²)，其餘零件只做平移、拉寬、歸一。**

- ✅ 四個零件：e^(−x²)、x−μ、除以 2σ²（那個 2 讓 σ 名副其實）、1/(σ√2π)。
- 🔄 為什麼偏偏是 e^(−x²)（Herschel–Maxwell，講到一半）。

### 對照表：四個零件各做什麼

| 零件 | 在公式裡 | 作用 | 拿掉會怎樣 |
|---|---|---|---|
| e^(−x²) | 核心 | 鐘形本體 | 沒有鐘形 |
| x − μ | 指數裡 | 平移到 μ | 中心永遠在 0 |
| ÷ 2σ² | 指數裡 | 拉寬；那個 2 讓參數 σ 剛好等於標準差 | σ 不再是標準差 |
| 1/(σ√2π) | 前面 | 歸一，讓面積 = 1 | 不是合法密度 |

記號（最後才出現）：

```
f(x) = 1/(σ√2π) · exp( −(x−μ)² / (2σ²) )
```

一句濃縮：**常態公式 = 一個鐘形原型 + 三個只負責搬家、拉寬、歸一的零件。**

## 陷阱清單

每條都是「❌ 錯在哪 → ✅ 正解 → 為什麼」，全部來自知識清單的 ⚠️ 條目。

1. ❌ 樣本變異數就是變異數 → ✅ 變異數是母體性質；樣本變異數（n−1）只是估計 → 為什麼：物件 vs 物件性質的 type error；估計量有自己的分佈，母體參數沒有。
2. ❌ 有界所以變異數有限、變異數有限所以有界 → ✅ 有界 ⟹ 變異數有限，反之不然 → 為什麼：決定動差存在的是尾巴衰減速度，不是有沒有邊界；常態無界但所有動差都存在。
3. ❌ 「這個算出來的平均數的分佈是…」 → ✅ 一個算出來的數沒有分佈；有分佈的是抽樣前的隨機變數 X̄ₙ → 為什麼：同樣是物件 vs 物件性質的混淆；數字是分佈的一次實現。
4. ❌ Cauchy 的均值很難找 → ✅ Cauchy 的均值不存在 → 為什麼：∫ x·f(x) dx 發散，不是數值上難算；這也是「尾巴相關的類別混淆（極端／無界／無變異數／不存在）」弱點模式的一例。

## 心智模型總結

```
μ      ← 機率加權平均（機制定義或樣本估計，數據不生 μ）
σ²     ← E[(X−μ)²]，用來算；σ 用來看
X̄ₙ     ← 位置→μ（LLN）、寬度 σ/√n（代數）、形狀→常態（CLT）
前提破 ← 看尾巴衰減速度：變異數無限 → stable；均值無限 → 不收斂
常態   ← e^(−x²) + 平移 + 拉寬(2σ²) + 歸一
```
